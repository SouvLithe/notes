理想国译丛这套书非常不错，而且最近很火，它的内容确实值得一读。每一篇沉浸其中你仿佛能感觉到思想的力量在流淌，然而正如任何伟大的思想体系都有其阴影一样，这套丛书也不乏一些充满毒素的观念，渗透在字里行距之间。就个人而言，这些思想并非简单的内容，它背后隐藏的是一股不容忽视的意识形态力量，一种在无声无息中改变你思维方式的潜力。
并不满足于表面的批评，所以挑出那些不合时宜、不合逻辑的部分，编者和作者们有时会藏匿其意图，如同弦外之音，暗搓搓地在意识形态上面插一手。不喜欢，所以去读原文，将这套书从头到尾进行一遍扶正、逐一去拆解书中地观念、去重构它们的内涵、梳理书籍中的内容和观点、分析理论。
# 01.没有宽恕就没有未来
真正的和解不能通过否认过去来实现，但直面野兽般的真相也绝非易事。
仅仅靠法律和政治手段是无法触及到人类心灵深处的创伤和仇恨的。
宽恕并非遗忘或者纵容，而是选择放下报复打破仇恨循环。
宽恕并不意味着你忽视了所有你所作之事，或者为邪恶的行为贴上虚假的标签，而是让邪恶行为不再阻碍你与施害者之间的关系。

注重宽恕的主体性和能动性之间的关系。
让受害者主动去超越痛苦和复仇的欲望，从而夺回对于自身命运和情感的掌控。
记忆是防止历史重演的关键，而不反击则体现了对于暴力循环的拒绝。
宽恕是治愈个体和社会创伤的关键。如果没有宽恕，人们一定会陷入愤怒、怨恨和暴力的循环，这只会加剧痛苦和不公。
怨恨和愤怒是腐蚀性的情绪，会阻碍人的蓬勃发展--人被过去的伤害所困，受害者在遭到创伤之后常常会被愤怒、怨恨和复仇的欲望所囚禁，这种情绪会消耗掉自身，也使它们长期受陷与施害者。

四重宽恕之路：
- 承认错误：让施害者面对并承认真相，让受害者去正式痛苦。
- 讲述故事：通过叙事和受害来表达其经历和痛苦，而听者则能见证其痛苦。
- 给予请求和给予宽恕：需要双方的意愿和勇气。
- 重建和释放关系：宽恕的最终结果并非总是导致关系的完全恢复，也有可能是建立一种新的关系。
任何试图掩盖或者粉饰历史的和解都是无效且有害的，对于避免创伤的代际传递至关重要。
- 报复性司法：将罪犯视为国家或者法律的侵犯，它的主要目标是确认罪责，并且施加惩罚，实现以牙还牙的报应。
- 恢复性司法：将犯人视为对人和关系的一个侵害，目标是让犯罪者对其造成的伤害负责，同时关注受害者的需求，修复破损的关系，促进理解与共存。
需要从根本上改变对于犯罪和正义的定义，将焦点从谁犯罪转向谁受到了伤害。为什么会犯罪呢？大多都是社会所造就的（刨除反社会人格）--社会伦理和人际关系。
传统的报复性司法被用来维护压迫，惩罚机制是无法解决社会深层的割裂的；实际上，不仅要关注施害者，也要关注受害者、施害者还有社会全部纳入到修复关系之中。

本体论基础：我因他人而存在，我的人性与你相连。
人之所以为人，是因为他与他人同在或者我因他人而存在，我的人性与你相连。
乌班图哲学是强调人与人之间的关联性的，我们常常把自己看作独立的个体、彼此分离，但实际上我们是相互连接的，你所作的一切都会影响到这个世界。
从这个角度看，宽恕并不仅仅是个体的选择，还是一种维护和恢复整体和谐的必要条件。
每个人的行为都能促进或阻止宽恕这一进程，而宽恕这一进程是宇宙核心进程。

是否存在不可饶恕之罪？
基督教神学：认为人类本质上是破碎的生命、努力成为人，所以每个人都有内在的荣耀和善良。即使是最黑暗的时刻也可以被掩盖和遮蔽。
个人层面的轻微冒犯导致他者的大规模报复（这个事情已经发生），极端罪行（大屠杀），宽恕是否可行或者适当？这是不是会先削弱到罪行的严重性，这是一个持续的伦理问题。
如果所有罪行都可被宽恕，那么正义和问责的意义是什么？
实际操作中宽恕、纵容、遗忘三者区分极其模糊，宽恕一旦和赦免挂钩，那一些加害者就会为了得到这些赦免去做一些事情。
这套理论（TRC）在国家层面并没有解决经济问题：财富和资源的不平等、土地掠夺以及教育和就业。--抓了贪官有用吗？其家属和亲眷已经拿着东西跑路了，惩罚太轻了。
那些通过罪责获得巨大经济利益的个人和机构，没有通道得到充分的问责，而扣动扳机的人却承担了国家集体耻辱的大部分。
# 02.漫漫自由路：曼德拉自传
读这本书，你可以去审视一个饱受系统性不公的废墟如何实现一个理想国。
自由不仅限于政治解放，还包含着社会和经济解放，预示着即使在名义上获得自由之后，工作仍在继续。自由是一个不断持续的过程，而非是一个终点。
只能在阻止斗争的消亡和持续的非人化这一更大的恶之间，选择这种必要的恶，以及讨论非暴力在面对绝对国家暴力时的局限性，还有在何种条件下，暴力成为一种可辩护但具有污染力的一种手段以实现解放的这个问题。
斗争是针对一个制度的，而非针对一个种族的。

自由、正义、平等、和解，这是作用最重要的四个哲学理念。
- 自由：不仅是政治压迫的消散还有基本需求得到满足。只要贫困存在就没有真正的自由
- 正义：意味着法律面前人人平等，参与立法权以及宪法保障所有人群的民主权利
- 平等：反对任何形式的统治，追求所有人和谐共处。
- 和解：个人宽恕和国家和解结合在一起。
避免基于身份的报复性正义陷阱，去追求真正包容和公平的社会。
将真相讲述和个人凝聚力置于个人的报复之上。
所有人之间有根本的相关联性，所有我们要基于共情、社群和关系修复来构建一个社会观。
剥夺人民的人权就是在挑战他们的人性。

革命性领导力的悖论性质：在原则上毫不妥协，在执行上务实且灵活。--很罕见的能力
变革性的领导力需要的是理想主义和实用主义之间的动态平衡，以及一些持续的自我批判与适应能力。
社会在冲突后的情景所面临的艰难选择：是考虑问责呢？报复。还是稳定呢？赦免。还是愈合呢？恢复。
魅力型领导人和象征型政治在法律或者经济措施单独可能会失败的情况下，可以用来弥补一些问题。
和解项目中存在一个根本性的问题--追求国家统一和稳定，一定会以牺牲个人正义和对受害者的全面补救为代价。特别是一些最脆弱的群体，真相换生命的交易对于那些受苦最深的人而言，是不完整的。因为没有解决他们对于物质赔偿的需求，也没有追究制度设计者和受益者的责任。
这种只有当暴力能够消灭更大的邪恶时才是合理的这一观点，与它的污染性和其所付出的代价相比到底要权衡哪一个
理想和现实之间是存在差距的，即使是最高尚的领导层，如果缺乏持续全面且可能会更加激进一点的社会经济改革措施与方案、一套秩序、一套结构，也是无法去克服根深蒂固的结构性不平等的。
政治解放只是漫漫长路的第一步，它并不会自动转化为经济再分配或消除继承特权的这些东西。

对于所有正在转型的国家来说，真正的变革不仅仅需要政治、领导层和法律框架的改变，还需要对经济结构和社会结构进行重新设计。
# 03.断臂上的花朵：人生与法律的奇幻炼金术
炼金术：是创造生命的禁术，生命与法律放在一起。
个人经历会塑造你的司法判断的。
论点：法官究竟可不可以对于司法中的主观元素，坦诚地说出来自己是主观的。
法律一定是作为现代世界人类尊严保护者的一个创造性的力量与思考。

每一个判决都是谎言。--并非是虚假性
而是指其形式上的最终书面判决的理性、有序的外观会让人觉得--这是一个基于理性的、一个自动驾驶的、一个你只需给输入，随后扔到法律这个机器里面就会获得输出的一个理所应当的现象。
但其实这个法律背后的决策相当的混乱。
作者一直在强调直觉和同理心在司法过程中的作用不容小觑，并且描述了洞察力如何在不设防的时刻、冥想状态中突然涌现出来的、这些洞察力又是在数小时的理性的调查、阅读、研究，和同事的辩论的基础上形成的。
司法完整性，作者并没有判决的合法性或内容的真实性，而是强调其在形式上是谎言的。
因为它掩盖了司法决策背后复杂、非线性、破碎的、充满了人性的思考过程，所以在阅读的时候可以超越表面。

法官的生命经验并非可观测的、或者现行的，法官的管情会让司法变得工正。
人类尊严，即人权。
什么是人类尊严？如何去保护人类尊严呢？--值得一直深思的问题
在疑难案件中，法官并非简单地去适用规则，而是必须诉诸于法律体系中地原则和政策以寻求最佳解释。

司法能动性和司法克制之间需要一种审慎地平衡--过度地司法冒险和过度地司法怯懦同样是有害的。
法官只需要在法治、维护法治和推动社会变革之间找到一个界限（很难找）
当法律被注入了对于人类尊严同理心和正义的细致理解时，它就能产生变革的潜力，所倡导的温柔的复仇，为分裂社会中的转型、正义和和解提供了一个不错的模式。
将个人苦难转化为对于正义的深刻理解，这种炼金术般的过程，就是让法律注入人性化的维度。
法律体系并非抽象的机器，而是由人类经验所塑造的活生生的工具，有能力促进所有人的公平、和解、正义和尊严。所以我们要思考在面对复杂社会问题时，如何将法律作为一种变革的力量，以实现一个更加公平和包容的社会。
# 04.历史的终结与最后的人
人类历史是否已经到达了意识形态演进的终点，即自由民主制是人类政府的最终形式。
核心的理论框架：历史的终结并非事件的终结，而是意识形态演进的终点，自由民主制的胜利。
历史演进的两大推动力：
- 自然科学的逻辑，科学知识通过技术改造自然的能力是累积性的，这种非倒车性的科学技术的持续进步创造了不断扩展生产的可能性，从而重重塑了现在的经济秩序。
- 为承认而斗争，人类不仅仅是追求物质复制，还渴望得到他人的尊严和地位的认可。这种对于认可的需求就是政治的根本动力。
人类渴望被视为具有内在价值和尊严的个体，这种普遍的愿望导致人类无法长期忍受威权主义的压迫，从而引发了抵抗动荡冲突和战争。

但有在后历史时期，曾经激发勇气、想象力和理想主义的一些意识形态斗争不存在了；取而代之的是经济计算、技术问题的无休止地提出与解决，环境问题以及对于复杂消费需求地满足。这种缺乏崇高追求的状态会导致人类变得平庸，甚至像历史开始前的动物一样----这种对于末人的担忧，解释了福山对于历史终结复杂而又矛盾的态度。

历史的终结：历史的终结并非事件停止，而是人类意识形态演化到最终形态，即自由民主制成为普遍且无矛盾的政府形式。
驱动力：自然科学的逻辑、为承认而斗争。
现代自然科学的逻辑：科学知识和技术是积累性的，推动经济发展和资本主义普及，它们形成了一个统一的经济秩序。
驱动力：科学技术进步、经济效率和市场机制。
为承认而斗争：人类对于尊严价值和地位的普遍渴望是政治和历史进程的根本动力，对于尊严的追求和自我价值的实现。
自由民主制：具有言论自由、自由选举、权力分立的基本要素的政治体制。满足人们对于认可的需求。

经济学基础：市场经济和全球化力量的分析。--现代自然科学的进步，创造了新的生产可能性，而市场是实现这一些可能性的最有效机制，中央计划经济无法支持技术创新，因为它们缺乏自由氛围和适当的经济回报，也无法获得市场定价中所包含的必要信息。
经济自由化能够带来快速的经济增长，进而促进民主政治的发展，最终扩大到民主和平区域来提升国家安全。
信息技术革命，作为现代自然科学的直接产物，加速了这一进程，因为它鼓励了灵活性、鼓励了权力下放、并使得政府和企业难以通过各个层级去控制信息从而控制下属。

亨廷顿认为的发展动力：是文明间的文化和宗教差异，历史的终点和发展方向是文明冲突而非意识形态的问题。
尼采的历史发展动力：历史的终点是克服虚无主义，创造新价值的超人，权力意志。
托克维尔：民主的不可避免，天意如此。终点是民主社会（可能会伴随着个体暴政和个体的平庸化）
马克思韦伯：理性化的铁幕，官僚制支配下的现代社会。关注效率与自由的冲突，去祛魅所带来的精神空虚。认为理性化是现代性的必然趋势，担忧人们会陷入一个非人化的铁笼。
卡尔布丹尼：市场扩张与社会自我保护的一个双重运动，市场社会对于人类和自然的破坏，呼吁市场对于社会的再嵌入。
阿伦特：公共领域的衰落、人类行动的丧失。因为集权主义对于人性的摧残、公共领域的消失、孤独与无家可归。

黑格尔认为真正的自我意识是社会和文化的产物，无法通过个体独立存在而实现
主奴辩证法：描述了两个独立的自我意识，在生死斗争中相遇，各自向对方证明自己的价值。在斗争中，一方失败成为努力，另一方成为主人。
这种主奴关系是不稳定的，奴隶通过劳动改造世界，并且逐渐认可自身的能动性和内在价值。而主人，则因其认可来源于被其物化的奴隶而无法获得真正的满足。
最终主人意识到它对于奴隶的依赖，奴隶则通过劳动和对思维的恐惧获得了对于自身有限性的一个认识，从而获得了一个更高的自我意识。
所有黑格尔认为，真正的自我意识只能通过相互承认来实现。
自由民主社会通过制度化的普遍认可，解决了主奴辩证法的矛盾，从而实现了所有公民的平等。

末人：富足和平的自由社会中，人类缺乏崇高追求，追崇于物质享乐。
日益增长的理性化，会将人们困在一个由规则和规范所构成的铁笼之中，从而削弱个人的自由和激情，导致祛魅。
集权主义的本质：在于对于人类多元性和公共领域的一个毁坏，将个体原子化并剥夺其行动的能力。
民主衰退：捍卫民主需要公民的积极参与和对于法治的尊重。
# 05.政治秩序的起源：从前人类时代到法国大革命
本书的立场：从早期的理想主义转为更加谨慎的现实主义，明确指出民主并不是实现政治秩序的唯一治理方式。
核心探索问题：成功的现代自由民主制所依赖的三大关键制度--强大的国家、法治和负责任的政府。这三点的起源、驱动力量、发展关系和相互关系。
由全球视野的比较历史分析方法。这样就可以将关注的焦点从单一的自由民主形式转为更为普遍的政治秩序的构建。
仅仅拥有自由民主的形式是不够的，缺乏有效国家能力去保驾护航的自由民主，只会让选民失望陷入政治衰败，所以提出有效国家、法治和负责制在内的政治秩序。

一个政府能够为人民服务、保障安全、兑现承诺才是政治秩序稳定与否的关键。
文化人类学和演化心理学：指出人类社会性自然地建立在两个基础原则之上，一个叫做亲缘选择（包容性适应原则），和一个互惠利他主义。
亲缘选择：解释为什么人类会倾向于去根据共享基因地比例、对于亲属或者视为亲属人表现出利他关系。
互惠利他主义：指出随着时间地推移，个体之间地互动倾向于发生出互惠互利或者互害的关系，这种关系不依赖于基因，而是依赖于反复的直接个人互动与彼此触发的信任。

强大的国家的特征：
- 国家能力：指国家掌握物质和意识形态资源，以及其强取、汲取和行政能力的一个共同结果，使其能够有效地去实现某些设定的目标。
- 非人格化的国家机器：意味着国家的运作是基于普遍的规则和程序，而非个人的情感偏好或者私人关系。
法治：
一群将社群结合在一起的抽象正义规则，其深层含义在于法律本身才是最终管制者而非统治者的工具。
管制者，这意味着法律不仅是用来规范市民的行为的，更重要的是它有效地限制了政府地公权力，使政府地行为必须受到法律地规管。
负责任的政府：
可通过公平自由的多党选举这些民主秩序，迫使统治者以全民利益为优先而非谋取一己私利，确保政府对于民众负责，必须存在足以和政府相抗衡的其它国家机构，形成制衡关系。

即使是表面上奉行自由市场的经济体，国家也在积极地塑造经济结构。
社交媒体会导致公共话语碎片化，这种碎片化会直接损害有效法治和问责制--所需要的基础就是广泛的共识。
通过赋能高度极化的少数利益团体、数字平台，加剧了否决政治的困境，使集体行动变得异常困难了。
# 12.罪孽的报应：德国和日本的战争记忆
负罪感、羞耻感在塑造民主身份和历史叙事中起到什么作用？
战后社会对于正常化非常渴望，这种正常化会掩盖集体创伤，还有一些责任逃避。
两国对于战争有各自的象征，日本是广岛，代表无辜的平民受害了；德国是奥斯维辛，代表德国的罪恶。
哀悼之劳：面对集体创伤和罪责时的一个心理过程，努力地去直面纳粹暴行。
真正地和平主义是否必须建立在对于历史罪责地彻底清算上？如果你不清理掉历史的罪，是否是一种自我欺骗？这一定会阻碍真正的和解。

民族记忆：它并不是一个简单的记忆、历史记录，而是由政治运动政府政策、文学艺术这种多方面的因素所塑造的一个集体意识。
这种记忆是有选择性的。
目的是服务当下的民族认同，抚慰一些集体良知。
《菊与刀》提出了罪感文化和耻辱文化的区分--西方是基于内在道德标准提出的罪感文化，而日本是基于外部评价的耻感文化。
一个民族能否真正面对其历史取决于其政治结构，而非固有的民族性格，强调民主政治参与的重要性，认为其可以抵抗军国主义意识形态。
国家对于历史叙事的选择，除了文化和心理之外，其实也是一种投资。

集体记忆：是一种社会架构，社群所共享，与群体身份密切相关地记忆、知识、信息。
沟通记忆通过交流；文化记忆是通过文本、纪念碑所固化地。
集体记忆它不是静态的，而是在不同世代之间动态地转变、选择性地继承。当亲历者逐渐离世地时候，集体记忆地载体就从亲身经历转向文化符号、转向教育叙事。
如果官方存在失语症，那么年轻一代就会对历史真相缺乏全面认知，会影响自己地身份构建，影响对于未来政策地判断。
这一代际也为历史修正主义提供了土壤，因为直接地记忆约束力被削弱了。
集体记忆可塑，意味着它并非是固定不变的历史真相，而是一个不断被协商、竞争和重构地场域。
罪责分为四种：
- 刑事罪责：违反了明确的法律，可客观证明并由法庭审判的。
- 政治罪责：国家行为的后果，公民需要承担责任。
- 道德罪责：个人在执行命令时的伦理责任，由良知判断。对于常态的顺从也是一种道德选择。
- 形而上罪责：作为人类，对于世间一切不公和暴行的普遍责任，尤其是在知情或者在场却没能阻止的时候。

打破社会的基本结构的疫情事件，我们称之为集体创伤，也会转化成集体记忆，形成一套意义系统，帮助群体重新定义自身。
对于受害者群体来说，创伤记忆有助于群体的生存，但是也会加剧我们的生存威胁，促使他们去寻求意义，并构建一些集体自我。
战争记忆是一个持续演变的过程，并非一劳永逸的终点，随着我们的亲历者逐渐的离世以及新时代的崛起，记忆的载体和形式将发生变化，而数字媒体和全球化趋势将进一步影响记忆的形成和传播。使得历史的真相传播更为广泛，但是它一定会被碎片化、一定会被简化，甚至会被扭曲。

历史是一个持续的、多维度的、一个及其复杂的过程。
# 13.档案：一部个人史
核心问题：是什么让一个人成为了抵抗战士，而另一个人却成了独裁者的仆人。
镇压的手段从早期残酷的身体镇压，转向更温和更隐蔽的心理操纵。
监控社会策略包括--系统性地败坏公共声誉、散布不真实但可信无法反驳地谣言，以及系统性地制造职业和社会挫败。涉及到了操纵私人生活、人际关系和职业生涯以引发个人危机，使受害者因为精神困扰而无法进行反政府活动。
利用行动心理学及其庞大地IM网络（界限人网络）对目标进行个性的心里化攻击，这种心理战术造成的长期影响包括--持续性焦虑、偏执、情绪障碍、缺乏自信、在社交中被孤立了。

社会信任水平显著降低，陌生人不相信陌生人，负面互惠性会更强，社交会更差，亲密朋友会更少，连志愿活动也消失了。

档案不仅解释了我们书中的内容，也通过具体的案例和理论对照，促使我们在阅读的时候可以将个人经历和宏大历史之间建立一些联系，更好地去联系过去，审视现在，对于未来可能发生的保持一个警惕心。
一直在呼吁的就是持续性的自我反思以维护自由社会的核心价值。
