# 什么是哲学
哲学的3个分支：
- 形而上学：理解世界、宇宙和存在的本质的思考（现实的本质是什么）
- 认识论：对知识的本质和范围的研究
- 价值论：帮助围绕你实际所做的事形成自己的思考
	一个分支是伦理学：研究人们应该如何相处
	另一个是美学：研究美与艺术

两步法：
- 永远要尝试去理解
- 需要调整自己进行一些严肃的批判性评价
# 如何论证
通过论证，人们是可以被说服的。
柏拉图提出，三重灵魂：
1. 理性：逻辑的灵魂，追求真理并被事实和辩论左右
2. 精神：感性的灵魂，性感如何激发你的行动
3. 欲望：物理方面，驱使你吃饭、性交和保护自己

前提，用来支撑你的想法
- 演绎推理：如果你的前提是真的，那么你的结论一定是真的
有效不等于真相（结论没有蕴含在前提中，就是无效的；如果你的前提中有任何一个是假的，结论也是无效的）
- 归纳推理：基于自然的可预测性，揭示出未来和过去往往在重要方面上相似
归纳的前提，仅意味结论可能是真的。
归纳不具备确定性，更关注可能性。
- 溯因推理：对最佳解释进行的推理
当排除掉所有的不可能之后，不论剩下的是什么、无论有多么不可能，那都一定是真相
它必须利用已有知识。

苏格拉底问答法：对话是最好的学习和接近真相的方法
# 现实的本质
不论现在看上去是多么显而易见的真理，都可能在后面被证明是错的。
平凡世界中的物质客体并不一定是最真实的东西。
# 怀疑主义
怀疑主义者，指怀疑我们是否可能确定地知道任何事情的人。
能确保自己没有相信任何错误事情的唯一方法就是 -- 不相信任何事
	如果仔细检查每一个可能的想法，只接收毫无疑问的事实，那么他就会知道自己仅仅相信着真实的东西
自我检查，弄清楚自己正在经历错觉骗局的能力，就是**局部怀疑** -- 关于特定感觉经验的怀疑或对其它特定时间内发生事情的怀疑。
**普遍怀疑**，无法置身事外跳出检查怀疑
笛卡尔《第一哲学沉思录》 -- 我思，故我在。（极端怀疑主义的产物）
- 无法怀疑自身的存在，可怀疑除此之外所有事物
# 经验主义
有些思想是清除且明确的，能以某种方式自证其正确性。
对怀疑主义的回答：
1. 理性主义
认为生活中最真实的东西是：思想，能够通过纯粹推理获得的命题
2. 经验主义
认为最真实的来源是：感觉（sense）。所有的知识都是通过经验获得的
洛克提出所有事物都具有。
- 第一性质，物理客体本身具有的性质。存在于物质。不取决于任何人，只与物体本身有关
- 第二性质，不是真实的，至少在客观上无法达成一致。不是客观真实的，只能被主观感受到

贝克莱认为，物质这种东西是不存在的，不可能存在，相应的只有感知。
提出：存在，即为感知（当感觉消失了，一切也就不存在了）
认为，上帝是最终感知着，总是不眨眼睛地注视感知着一切，以维持事物地存在，甚至在我们没有留意的时刻。

# 论宇宙
哲学困境：
- 无限倒退：在一连串的推理中，链条上每一点的证据，都依赖前一个点的存在，以此类推没有起点。(一定有一个可信的起点)
存粹的偶然性是天然的，必然之根是偶然的 -- 看似坚固的必然规律，其深处往往隐藏着不可消除的偶然性。

# 存在主义
本质：某种使事物成为自身的必要本质的特定核心
本质主义：你与生俱来，就是为了成为特定的存在
虚无主义：信仰生命终极无异议
存在主义：存在先于本质
荒诞：在没有答案的世界中寻找答案。
# 同一性
同一性：事物只与自身存在的关系 （什么使物体跨时间保持一致）
不可分辨的同一性：如果任意2个事物是同一的，那么它们必须具有完全一样的属性。
本质属性：事物成为自己所必须的核心元素
偶然属性：可以从物体身上拿走而不会使物体变成另一样东西的特征
可替代性 和 不可替代性 会出现是因为有些时候人们在意的是物品的价值。

人格同一性：肉体理论、记忆理论、
# 决定论与自由意志
政治自由主义：不受政府干预的自由，而采纳自由意志的人
强决定论：一切现在发生的事，都是过去发生的事的必然结果
自由意志：相信人们的行为来源于自己的选择
有自由意志的人类行为源自：信念、欲求、偏好
选择：只是一系列神经物质，以恰当的方式结合的必定结果

相容论：有时也叫弱决定论（决定论+自由意志）
# 语言与意义
代词：指明物体或概念的一个词
涵义：将我们、物体与概念联系起来的方法
如何获得意义：通过搞清楚成为某事物充分必要条件，那么你就有了自己的定义
你给出的任何定义，都会有人提出反例，或者有一些例子被这个定义排除在外，或者有一些定义包含的东西并发每个人都同意是该客体
了解词语的意义，通过听语言共同体中其它成员使用的词语方式，从词语方式这些拼凑出共同点，这种识别被称为 **家族相似性**
词语的意义是 -- **集群概念**，不存在任何一个元素，是集体所有成员都共有的，但每个成员都与其它成员有一定的共同点

并非集群中的所有概念都同样重要：
- 每个人都接收的概念，叫 典型例子
- 有人把概念包含在集群内，有些会排除， 边缘例子
意义 在于 使用 -- 只要一个语言共同体以特定的方式使用词语，词语就有意义
# 言外之意
谈话的准则：
- 数量准则：应该提供充足的信息；不应该提供过多的信息
- 质量准则：不应该说我们认为是错误的事情；不要给缺乏充分证据的事情下结论
- 关系准则：说相关的事情
- 行为准则：不要说含糊不清的短语；杜绝歧义；简洁；条理清晰
# 伦理学
研究道德，即对与错行为的哲学分支。

正确之所以正确，是因为上帝是这么规定的？还是上帝规定正确的行为，因为这些行为本身是正确的？
	如果正确之所以是正确的是因为是神规定的，那么上帝可以规定任何他想规定的
两难困境：你必须从2个选择中选择1个，每个都会导致不愉快的结果
# 康德与绝对命令
假言命令： “如果-那么”的命题
公式1：仅依据那种你同时可以意愿它成为一项普遍法则而不自相矛盾的准则行动
公式2：不论是对待自己还是他人，应当将人视作目的，而非纯粹的手段
# 论道德
人们只能道德地要求你可能做到地事。
- 因果责任：你身处事件因果链
- 道德责任：你值得因发生的事获得积极或消极评价。
