## 字符串
当数组用new转成字符串时，每个字符单独一个内存。
![[Pasted image 20250712104041.png]]
当不用new时记录的是串池（StringTable）里面的内容，用的话记录的是堆里面的内容。
**字符串拼接的底层原理**:
![[Pasted image 20250713233932.png]]
- **无变量参与**：若拼接的是字符串常量（如 `"a" + "b"`），编译器会在编译阶段直接合并为 `"ab"`，并从**字符串常量池**中复用已有对象，效率最高。
- **有变量参与**：若拼接中包含变量（如 `str1 + str2`），JVM会在运行时通过`StringBuilder`（或`StringBuffer`）动态创建新字符串对象，导致**多次内存分配**，可能浪费空间。

### default方法：
![[Pasted image 20250718182624.png]]
- **向后兼容性**：允许在接口中添加新方法，而不会破坏现有的实现类。
- **提供默认行为**：为接口中的方法提供默认实现，实现类可以选择性地覆盖这些默认实现。
- **增强接口的灵活性**：使得接口的扩展更加灵活，可以随着时间的推移逐步增加新的功能。
- **支持函数式编程**：在函数式接口中提供辅助方法，而不影响其作为函数式接口的特性。
### static方法：
![[Pasted image 20250718183034.png]]1 .接口代表规则，是行为的抽象。想让哪个类拥有某个行为，就让这个类实现对应的接口即可。

### 函数式接口
**函数式接口**（Functional Interface）是 Java 8 引入的一个核心概念，指的是**有且仅有一个抽象方法**的接口。它通常用 **@FunctionalInterface** 注解标记（非必须，但推荐），主要用于支持 **Lambda 表达式** 和 **方法引用**。

## Lambda
![[Pasted image 20250724001323.png]]
Lambda表达式最大的作用就是简化匿名内部类。
可以用加@FunctionalInterface看看是否报错的方式检查是否式函数时接口。
函数式接口就是只有一个抽象方法的接口。
![[Pasted image 20250724001131.png]]
函数式编程思想：忽略面向对象的复杂语法，强调谁去做而不是做什么。更加关注方法体中的逻辑而不是对象。
### Lambda表达式的省略写法
核心思想：可推导，可省略。
```
Lambda的省略规则：
1. 参数类型可以省略不写。
2. 如果只有一个参数，参数类型可以省略，同时 `()` 也可以省略。
3. 如果Lambda表达式的方法体只有一行，{}、;、return 可以省略，但若要省略需要前面三个同时省略。
```
