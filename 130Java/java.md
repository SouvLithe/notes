Java类：
>构造器与类同名。
>每个类中可以有一个以上的构造器。
>构造器可以有0个、1个或多个参数。
>构造器没有返回值。

它是一个纯面向对象语言，没有（python）函数的概念，只有方法，它所谓的函数返回依赖访问器（单纯构建了一个return方法的函数）。

```
class Calculator{  
    private double a;      //局部变量，3个
    private double b;  
    private double c;  
  
    public Calculator(double a, double b){ //实例化  
        this.a = a;  
        this.b = b;  
    }  
  
    public double makeAdder(double e){  //这个e是参数
        c = this.a + this.b+ e;  
        return c;  
    }  

    public String makeAdder() {
        return "Use makeAdder(double e) to add a value."; //返回默认值
        // return makeAdder（1）； 返回一个默认值
    }
}
```
无参构造函数返回的是函数情况下的默认值。
- **`final`**：实例常量（一旦定义不可改）
    
    - **变量**：值不可变，线程安全，优化。
        
    - **方法**：不能覆盖，优化。
        
    - **类**：不能继承，防止被改。
        
- **`static`**：类变量（可改）
    
    - **变量**：类级别的，节省内存，便于访问。
        
    - **方法**：类级别的，独立性，便于访问。
        
    - **代码块**：类加载时执行，初始化类变量。

>按值调用：表示方法接受的是调用者提供的值。
>按引用调用：方法接受的是调用者提供的变量位置。

Java总是按值调用。调换对象时，数据存放的物理地址本身不变，调用的只是指向物理地址的索引。

### 包的引用

从编译器的角度上将嵌套的包之间没有任何关系，每一个包都是类的集合。
>只能引入一个特定的类或者整个包。（不能引入以某个前缀为首的所有包）
>如果不同包中有两个相同的类，应该在每个类中加入完整的包名，避免编译器混淆报错。
>import方法允许导入  静态方法  和  静态字段  。//import static .....

在包中定位类的是编译器的工作。类文件中的字节码总是使用完整的包来索引其他类。


签名：  方法的名字  和  参数列表  称为方法的签名。
方法表：因为每次调用方法都要完成一次搜索，时间开销大。所以JVM预先为每个类计算了一个方法表，其中列出了所有方法的签名和要调用的实际方法。

final类：不允许拓展的类。
 `default`：表示这是一个默认方法，可以在接口中直接提供实现，而不是强制要求实现类必须实现该方法。

使用  @Override  标记要覆盖超类方法的那些子类的方法。

装箱和拆箱是编译器做的事情，不是JVM应该做的。

Java没有提供途径将一个方法的存储地址传给另一个方法，以便第二个方法以后调用。
Java觉得方法指针很危险，而且容易出错，相反它们认为Java的接口和lambda表达式是一种更好的解决方案.

静态方法 (`static`)属于类本身;非静态方法属于类的实例（对象）
数组构造器引用对于克服java的无法构造泛型类型T的数组这个限制很有用。(表达式new T[n]会产生错误，因为这会“擦除”为new object[n])

声明局部类不能由访问说明符。
代理可以再运行时创建实现了一组给定接口的新类。
代理类是在程序运行过程中动态创建的。
所有的代理类都拓展Proxy类。一个代理类只有一个实例字段——即调用处理器，它在Proxy超类中定义。完成代理对象任务所需要的任何额外数据都必须存储在调用处理器中。
对于一个特定的类加载器和一组接口，只能有一个代理类。
代理类总是public 和final。

## 泛型程序设计
java常用变量E表示集合的元素类型，K表示键的类型，V表示值得类型，T（必要时还可以用相邻的字母U和S）表示“任意类型”。
- **`?`**：无界通配符，表示未知类型，只能读取集合中的元素。
    
- **`? extends T`**：有界通配符，表示未知类型是 `T` 或 `T` 的子类型，可以读取集合中的元素。
    
- **`? super T`**：有界通配符，表示未知类型是 `T` 或 `T` 的父类型，可以向集合中添加元素。

## 并发
并发执行的进程数量并不受限于CPU数，OS会为每个进程分配Cpu时间片。
多进程和多线程的区别，每个进程都有自己的一套变量，线程则是共享数据。
线程调度的细节依赖于OS提供的服务。

所有现代桌面系统和服务器OS都使用抢占式调度，但。手机这种小型设备可能使用协作式调度，（小型设备中）一个线程只有在调用yield方法或者被阻塞或等待时才失去控制权。
在有多个处理器的机器上时，每个处理器可以运行一个线程，而且可以有多个线程并行运行。

>一定要记住,在给定时刻，一个可运行的线程可能正在运行也可能没有运行（出于这个原因，这个状态被称作“可运行”而非“正在运行”）
