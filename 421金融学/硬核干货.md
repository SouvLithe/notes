# 股票投资的框架体系
## 技术分析
说白了就是看图说话、找规律，
主要是分析股票过去的走势，比如说价格、成交量、波动率，
然后去预测它未来的变化。

结论：不建议特别过分依赖技术分析。
因为：现实中有大量的量化型对冲基金或者一些交易公司，利用Iceberg冰山模型、Ninja忍者模型，去分析整个市场里面的交易量，
当市场上一旦出现小偏差（供需不均），它们的钱就过去了，这时候你可能还在两公里开外。
即，消息不均。
还有数据工程师--不光建模，还会从市场上各种新闻里面做 “Text Mining”（文本挖掘--挖掘文字，把文字转化为一个信号，然后参与到交易的决策）。

价格短期来讲是供给需求决定的，长期来讲是价值决定的。
供给需求量的分析，一般而言，更适合短期的投资。
所以对于中长期投资而言，技术分析风险比较大。
在关键点位附近，就不再是正常的一个股票价格或者股票收益率的分布，会有一些离散值。（过分依赖这个的话就得承担更大的风险）

# 比特币资本战
加密货币的中心思想：去中心化。没有一个像银行或者政府的一个中央管理者。
没有中心如何保证：
1. 让所有人接收信息
2. 保证信息准确
3. 用户账号安全
解决方法：区块链技术、非对称的加密技术。
受益者：
- 投机者：商品满足波动率高、流动性高、噱头性高属性就会蜂拥而至。
- 机构投资者/公司：财政/货币双宽松，导致公司手握大量现金、通胀风险激增、负真实收益率。因此会利用比特币来分散风险。
- 蹭流量的：吃瓜群众的谈资。
- 整个产业链的参与者：新产业的出现其上下游都会跟着受益。
- 黑市交易者：在黑市中充当货币的职能。
比特币为什么适合对冲风险？
- 存量有限--保值。
- 零相关性（不管价格怎么变，比特币就走自己的）--分散风险
- 历史高收益率--收益
# 信托
言而有信，受人所托。一种投资理财方式。
最重要的三个角色：委托人、受托人、受益人。
委托人因为某种原因，把财产交给受托人保管，最终收益是要分给受益人的。
但，一旦把钱放在信托（单独的个体）中，钱就不属于三方的任意一方。
信托的特点：不可撤销的。

应用：
- 遗产管理（梅艳芳）
巴菲特关于遗产这样说：一笔恰到好处的遗产，是给子女们足够多的钱去做任何事，但又不多到它们什么都不用做。
- 婚姻财产保护（刘强东、默多克）
- 隔离财产（贾跃亭）
融资需要签订对赌协议。就算创业失败了，还可以从这个信托里面拿钱。
- 避税（特朗普他爸）
遗产的赠与税和遗产税，如果要给妻儿老小要交一大笔钱，放到信托里细水长流交的相对就少很多了。
- 隐私保护
在国外大额消费在网上是可以查出来的，不希望公之于众，搞个信托让信托来买

信托成本：
1. 建信托，需要一个律师处理一大堆法律文件（1k-3k刀）
2. 贵在管理
你要找一个专业的信托公司作为受托人替你管钱，它们会根据你的意愿、给你量身定制、一个最适合你的方案，然后后期还需要执行，那你要付他们的工资。
一般你的流动资产达到100w美金以上，差不多千万人民币级别的流动资产（不包括房产），如果又上述需求可以考虑一下。
# 金融
金融，让钱更合理地配置。
三个身份：融资人（贷款人）、中间商、投资人（借款人、投资人）。
这些身份可以是个人，也可以是机构。

1.0版本：贷款人<-->借款人
金融，就是钱的流动。让钱走到更能产生更大价值的地方上去。
提高了社会的整体福利，同时提高了资源配置效率。

2.0版本：贷款人<-->中间商（银行）<-->借款人
中间商帮助借贷双方联系到彼此，同时自己也可以利用这批钱做一些事情赚取利润。

3.0版本：贷款人<-->投资人
高风险高利率，低风险低利率。
中间商不愿做风险过高的事情，所以贷款方需要找到愿意追求高回报、且能承担高风险的人。
希望得到高回报且能承担高风险的人的钱，可流到高风险高回报的项目上去了，专业名词叫做股权投资（融资），也叫私募。

4.0版本：贷款人<-->中间商（投行、券商、FA）<-->投资人
- 银行是把自己的钱借给贷款人的，中间赚差价，它是承担风险的。
- 投行只是提供一个服务，把双方牵线牵起来，只收个服务费，之后便是你们自己的事情了。

5.0版本：贷款人<-->中间商（投行、券商、FA）<-->大众（投资人）
贷款人的股份，通过股权公开发行给大众，让零零散散的散户参与进来称为贷款人的股东。
这就是 上市、IPO、敲钟

还有一个角色--基金（所有类型投资者的集合），会汇集很多人的钱，然后按照特定的需求去投到特定的产品里面去。
像平时听说的：私募基金、风投基金、养老基金、对冲基金等等都是基金。
基金可以投给另一个基金，形成嵌套，导致非常复杂
中间商，可以帮你发股、发债、上市，只要有资本市场的需求，就努力帮你完成，在中间赚取中介费。
还可以在流通市场里面提供服务，买些特殊产品、衍生品他都可以卖给你，提供市场的流动性。
这种发行之后的交易，也是平时说到的--二级市场的交易。
这也是为什么有的人，管投行叫卖方（卖的是服务）。
有些大型公司，会同时具备上述的三种角色。
# 基金
投资怕被割韭菜，没别的办法，只有不断提高认知，达到信息对称，理性思维占据智商高地。
建立基金的框架，之后就很难人云亦云被忽悠了。

基金，就是把钱凑起来交给一个人管理，这个人就叫做基金经理（PM）
基金可分为：
1. 私募基金：私底下募集，说白了就是大众买不到的基金。
如，对冲基金、风险投资基金（PE/VC，PE指 私募股权基金，VC指 风投基金）
针对的是：可以承担高风险的人，比较玩得起
因此监管不怎么严格，基金经理拿到钱后，怎么赚钱就可以怎么玩--比如高风险的 期权、期货、衍生品、杠杆交易、挖挖大数据、做空、恶意收购等等。

2. 公募基金：公开募集的基金。
公开募集，很多人会把所有积蓄投进去，那监管要求就更严格了，相对可控。
最常买的主要是两大类：
	1. 共同基金，也叫普通基金
	一般提的买基金就是指的买共同基金（海外叫Mutual Fund，国内有个创新叫LOF），可以像买股票一样在二级市场上流通。
	2. ETF（交易所交易基金）
	买了一个ETF相当于买了一个大盘，一个指数。可以是双倍，也可以是反向等等
两者区别在于：共同基金有人给你管，但绝大多数ETF都是追踪一个指数的（ETF的价格走势基本上和它追踪的指数是相差无几的）
怎么选：两个点，费率（管理费和托管费），谁来管钱

有效市场假说：如果证券市场是有效的，那么价格就会反映到市面上所有的信息，不存在任何的不合理定价或者套利空间，市场是有效的、完美的。

# 避税
只有死亡和税收是不可避免的。
政府会在你的获利当中收取一部分地比例，实际很复杂。
和我们收入获利相关地税主要有三大类：
1. 直接收入：实打实地收入，要交个人所得税和收入税。
2. 财富增长：投资增值税（资本利得税），买的东西增值了，增值地部分要交一定地税。（国内不交）
3. 财富传承：遗产税（国内没有）
## 直接收入
收入税 = （收入-成本） x 税率
减少收入：拿一块钱工资的人都是手持巨额股份的人。
增加抵扣的成本：将开销算作公司的成本，以此来抵税。但不是什么都能抵，必须要是和公司业务相关的成本才可以。
进阶的增加抵扣成本--搞慈善。真捐；捐赠人建议基金（捐钱的人可以决定钱怎么化）；艺术品捐赠，但不知道多少钱，可以由一个专业的机构来“鉴定一下”。
从税率入手：
把收入从一个高税率的类别，降到一个低税率的类别。（成立公司，转移公司地点）

富豪的财富积累和增长主要是靠：公司的股价增长和市值的增长。
## 财富增长
当你要变现的时候，就是你要实现收益的时候，要收增值税。
但是，如果你一直不套现就不收税。
股票涨了是纸面价值，总不能一辈子都弄个纸面价值，总有一天要把钱拿出来。
	引出避税的一个重要操作，对于富豪而言纸面价值也是价值，这个价值我不用拿出来花，但是可以用它去借债。
那要说了--股票暴跌了怎么办，那么担心的就不是避税这件事情了。
## 财富传承
避税方式：信托，家族慈善基金会
# 股票分析-找潜力股
挑选本质就是：核心三加一，3指3个量化指标，1指一个非量化的定性指标。
## 量化指标：
- 盈利能力：衡量指标--毛利润率、净利润率、营业利润率等。
只挑一个，最多看的是净利润率（净利润/总收入）
高利润率可以帮助企业低于更多风险。
不同行业因为运营模式不一样，所以净利润率的差别会很大，在看这个数字的时候需要和 行业平均 或 同类型的公司作比较才有价值。
主要：
	假设有个公司口碑、形象、品牌做的都好，就是不赚钱，作为消费者就会去买，但是作为投资者一定要小心
	很多高速成长期的公司，因为要迅速扩张，就要砸钱补贴，那么它们的净利润率很可能是负的。这种情况可以看 **毛利润率**（扣去了所有直接成本下的利润率） 进行比较

- 财务健康：资产状况如何，高不一定说明你有多优秀，低了肯定不行。
最常见的指标--流动比率（流动资产/流动负债），一般情况建议大于1.5

- 价格水平：好的公司不一定是好的股票，我们希望在一个合理的价格买入。
常用指标--市盈率（股价/每股净利润）
市盈率，可以理解为抛开折现和各种因素不谈，多久可以把股价赚回来。
## 非量化的定性指标
可能比上面三个更重要，即护城河。
护城河，有的时候你可以叫他核心竞争力、比较优势。即如果一个商业模式被验证了可以赚钱之后，那么其它公司是不是很容易学你、超过你。
一个强大的护城河对于公司的长期盈利是至关重要的。

护城河分为下面几类：
- 品牌：商品不再是商品本身了，品牌赋予了他独特的价值。
- 网络效应：但你的产品达到一定规模之后，他就会自发地往上涨。
- 转换成本（用户粘性）：用一个东西，倒不是这个东西有多好，只是因为用习惯了懒得换。
- 专利。
# 上市
就是上到市场上，指原来不公开地公司把新股发到一个交易所，这样大家就可以在市场上公开进行买卖。
上市主要两大好处：圈钱（融资）和套现。
- 融资（对公司而言）：稀释股权，融到更多地资金用于公司发展
- 套现（对个人而言）：手中的股份流动性很差交易，成本很高。公司上市了就会改变这点
股票上市，如果买的过快，股票会下跌。因此早期上市时，都会有一个叫锁定期（Lock up period），这个期间股票是不能卖的。几个月到两年不等。
并且，公司的大股东的持股信息是对外公开的，他们的行为会受到外界关注。
上市还有一下，两大优点：名声 和 降低再融资成本。

上市的成本：
- 股权被稀释了
- 纰漏信息
- 时间（美国上市 1-1.5year，国内1-4年）&金钱（投行，律师、会计师）
美国上市，叫注册制。
中国上市，之前叫核准制，现在往注册制转。
注册制，指公司准备好材料交到证监会，证监会对材料进行审批，材料OK，就可以注册上市了。
核准制：先看你的材料，材料OK了，再看你的公司背景。
- 未来管理成本。
公司本来发展应该以长远为目标的，上市之后，受到财报，大众股价影响的绑架，就会更加注重短期利益。这就是对长期发展的成本。

上市方式：
- IPO：首次公开，把股票发售出去。
- 直接上市：不找投行帮我运作和找投资人，直接把我公司的股票放到公开市场上交易。要求公司有一定影响力。
- 借壳上市（反向收购）：私有公司收购了一家上市公司，私有公司把业务放在上市公司。

# 退市
退市，大众之后没办法在公共市场上买到这个股票了。
可以分为以下几类：
## 自愿退市
原因有三种：
1. 不愿被短期利益绑架
上市是有成本的，
有没有办法既可以开展一些业务为长期的发展考虑，同时又不用受短期的利益牵制或者舆论绑架。--退市。
即花钱把市场上公开流通的股票回收，变回私有公司。
所以自愿退市也叫“私有化”。
2. 资本买断（通产由于企业有进一步优化空间）
3. 股价低（公司/管理层现金流充足）
## 非自愿退市（强制退市）
情况有以下几类：
1. 公司的经营状况不好
股价\净利润等长时间低于一个标准时，就要退市了。
```破产
1. 破产清算
   公司不干了，把资产变卖了还给股权人；如果你持有这个公司的股票，大概率到后面什么也不剩了。
2. 破产重组
   可能因为短期出现现金周转的一些原因，现在债还不上了；但持续来讲，之后可能把这个债再换上，就可以申请破产重组。
```
2. 财务造假（瑞兴） 
退市之前还是可以交易的，如果没有交易，后续会转到一个场外市场去交易，在场外市场它的流动性就会变差。
3. 法律要求
## 强制的自愿退市
如滴滴，从美股退市，再到港股上市的时候，是一个叫ADS的形式
ADS，有一个银行买了企业的股票，在中间经过一系列操作以ADS的形式挂到纽交所，这样美股的投资人就可以在纽交所进行公开买卖了。
企业应在港交所上市，然后把这些ADS从纽交所摘牌，然后以一定的协议转到港交所这边。
如果你持有ADS，即持有企业的美股但是不卖，相当于你从美股的投资人转成了港股的投资人。

# 做空
想做投资，看上一个股票/期货，
预期它会涨，就低买高卖从而赚一笔，这个叫做买入、做多、也叫Long；
预期它会跌，就高卖低买从而赚一笔，这个就叫做空或者卖空。
![[Pasted image 20251224082503.png]]
个人做空投资者，可由证券公司辅助帮忙找愿意卖股票的人；机构做空投资者，可以由投行（里面有个专门的部门Prime Brokerage Group，主经纪商业务组）来服务你。
做空就是做多的一个反向操作。一个想让股票涨，一个想让股票跌。
## 真实世界的做空
做空面临的将是：有限的收益和无限的损失。
做空在大多数情况下都会伴随着对冲--当做空一个股票时，我会再做多一个股票或者做多一个大盘的股指期货。这是一个非常常见的对冲基金策略，叫做“Long-Short Strategy”多空策略。
那么即使老王这边你没赚到钱，你也可以从大盘整体赚到钱
做空不仅要判断对方向，也要判断对时机。

**浑水做空流程；**
	秘密走访 -> 财务调查 -> 找到做空公司后做空  -> 发报告  ->  股价跌  ->  获利平仓、捞钱走人
找这种公司标准--大的、流动性好的又存在欺诈的
- 这种做空对象实际上是有限的，最后一种性质与前面两者负相关。

**资本攻击--大佬的做空方式。**
当大佬感到市场上，某种资产的价值被高估了，并且他感觉很多人也有同感，但是出于某种原因，这个资产的价位一直处在高位的时候，大佬就可以用海量的资本去戳破这种市场的幻象。
如果在市场上得到足够多的强反馈，那就会强行地把资产拉回到一个合理地价格区间。即一个很好的回调机制。
但有时也会引发一些恐慌、踩踏、暴跌，甚至引发金融危机。这也是很多空投都非常找骂地一个原因。

金融的本质就是信用，就是市场对你的信心。
- 市场觉得你行，你就行，不行也行。
- 市场觉得你不行，你就不行，行也不行。

做空外汇和做空股票是两个概念。
- 在做空外汇的时候，你做空一个货币，实际上变相做多了另一个货币。

**资本反击**
资本攻击的同时回伴随着强烈的资本反击（股东、管理层，希望股票涨的人；券商、做市商，希望市场活跃的人；媒体、投行、研究机构）。
对于做空方而言，要么你得有足够多的量，要么有足够多的弹药，才能检查下去和上面这一群人对抗。
```Multi-Level Marketing
任何一个人都可以称为改品牌的独立销售，独立销售可以以折扣买到他们的产品，每卖一单能拿提成。
你可以拉别人进来成为你的下线，它卖出去的产品你也可以拿到提成，你下线的下线卖出去的话你也可以拿到提成。
```
HerbAlife营销手法，这种方法又叫“Multi-Level Marketing”多层次营销
- 多层次营销和传销的界限很模糊：如果最后产品买到消费者手里，可以叫他多层次营销；但如果只一层一层从下线中赚钱，就是传销。

**轧空**
由于被迫清仓导致股价飞涨就被成为轧空（short squeeze）。

# 利率
各国央行最大的动作就是调整利率。
利率，可以理解为钱的时间成本。
- 降息之后，会减少储蓄并增大消费和投资。整个经济体就更活跃了，整个经济体就会产生一个良性循环。
降息会增加通货膨胀--需求旺盛导致商品涨价，原材料也涨，最后大家工资也跟着涨了。
- 加息短期之内会抑制经济，长期会抑制通货膨胀。
 ![[Pasted image 20251230080050.png]]

银行贷款包括利率：
- 风险溢价：借贷人的财务状况
- 油水：银行要赚的钱，看银行情况
- 无风险利率：整个经济的根本，看到市场上恶所有利率（存款利率信用卡利率、房贷利率、债券利率都基于无风险利率）
无风险利率，指肯定能还的上钱的人贷款所需要的利率。现实世界中最接近无风险的就是较大经济体的政府，被近似认为是无风险的。
	那么这些政府发的国债就可以看成是对应货币的无风险利率。
国债在二级市场上可以交易，可对应一个价格，**价格能到推出利率**

把利率画在一个横轴为时间的图上，这样就会形成一条曲线，即货币的无风险利率曲线（Yield Curve）。
	这个曲线就是整个经济体的基准，就是经济体的根基。
	通常是向上倾斜的，即长期利率高于短期利率。
	如果向下倾斜，被称为 **利率倒挂**。
央行控制的是短期的利率：
- 英国、欧洲央行控制的是隔夜拆借的利率，即一天的利率。
- 中国央行控制的是7天的利率（逆回购利率），最近增加了一个中期借贷便利叫MLF，俗称叫麻辣粉（大概是3个月到一年期的利率），长期的话可能听说央行控制一个叫做LPR（贷款市场报价利率）。
美国的隔夜拆借利率，即联邦基金利率是最近听说的各种加息。
剩下的所有利率，都是通过国债市场或者MBS市场来影响的，不是央行控制的。
央行控制的是短期利率，长期是由市场供求决定的。
央行可以使用如下影响它，但无法直接控制：
- **量化宽松（QE）**，央行印钱到市场上参加那个公开市场操作，把长期利率压下来。
![[Pasted image 20251230084341.png]]
利率，与通货膨胀、债券负相关，与股票弱弱的负相关，与汇率正相关。

# 房地产
房地产市场特点：
1. 刚需：谁都需要。
2. 投资品：其价值并不取决于它实际对你带来的那个效用，而取决于你预期它未来在市场上的价值。（越买越涨，越涨越买）
房子连接着经济体中的每一个人，而且越不富裕的家庭，这个连接就越紧密。
3. 信用深度绑定：买房需要贷款。（信用扩张导致房价上涨）
	大部分金融产品抵押规则：贷钱买股票，买了股票把它放在银行做抵押物，假设抵押物下跌，银行打电话问你要保证金；（风险由贷款方承担）
	房地产抵押规则：抵押物变成房子。房子由银行拍卖，房子交易成本极高，拍卖的话拍不到市场价。（风险由银行承担）
	**信用危机：** 房价下跌、违约增加 -> 银行损失 -> 银行收紧放贷 -> 流动性收紧 -> 经济活跃度下降 -> 总需求下降 -> 经济陷入衰退
房地产一崩信用就崩，信用崩银行就崩，银行一崩所有人玩完。
房地产危机：绝大多数情况下，都是信用危机和银行危机。

如果站到整个经济的视角来看，就是这些投资品的价格波动理论上不会影响到实体经济的。
但是如果财富增长的时候人的消费实际上会增加，为什么呢？
	**财富效应：** 因为你知道你的财富增加，消费也会跟着增加，而这部分消费的增加它确实增加了，没有任何其它的东西给抵消掉。
房价上涨带来的财富效应（持房人暗爽，买房人攒钱）并不明显甚至可能是负的，但在房价下跌的时候，这个效应就十分明显。
当房价下跌暴跌的时候，房地产市场带来的这个负的财富效应是经济谁退的一个非常重要的因素。
这也是房地产在宏观经济上由举足轻重的地位：
	房地产市场作为刚需，紧密联结着消费者，它是一个巨大的信用市场。房地产泡沫破裂导致的信用危机和财富效应会给一国经济非常沉重的打击。


房价判断的理论很基本：就是供给和需求的分析。
房地产分析在学术界没有没有特别成体系的理论框架。

**房地产需求因素：**
1. 人口。
看年龄分布图，
把时间维度拉到十年这个维度，增口增加必然导致房子这一刚需的上升。
看就业人口、人口、高收入人群人口走势曲线图，
其次，就是如果移民政策发生了变化或移民趋势变化，那么房价就会调整。
2. 经济状况
GDP衡量的是整体的经济，很大一部分是企业的收入。
衡量与个人相关的经济，可以看人均收入或者就业数据。
预测未来人均收入变化，看历史走势--很多投资人会看中位数人群的收入走势、就业的数据、失业率。
**预测方法：把过去的走势连在一起往上连虚线**
**必须要理解数据背后的逻辑，就是这个数据是由什么支撑的、稳不稳定**，经济这块用收入衡量是比较大多数的情况。
外部投资，即游资也是一种特别的力量，对应金融市场开发的地方值得关注一下。
3. 利率
利率高，贷款贵，需求少。
4. 政策
购房优惠、购房限制、税收等。
>前两个因素是市场因素，更底层、长期是起到决定性作用的。
>后两个是行政因素，一般短期立竿见影。
>总和四点考量基本上就能得到房地产需求分析的大致框架，但不要盲从。
>房地产泡沫、信用泡沫其实也满足这四个条件，信用泡沫一般也是在这种低利率的宽松环境下培育出来的一个经济过热的现象。专业的房地产投资人它们的分析也是通过这四条反向助长了这个泡沫。

**房地产供给：**
就是市场上净增加出售的房子。
因为土地有限，房子的供给波动不大；而且房屋供给受劳动力限制，弹性比较小。
一般衡量房屋供给会用数据 “Housing Starts”新房开工，统计的是已经申请下来牌照的新盖的居民楼。
供给端一般影响力不如需求端，但分地方。

# 通货膨胀
常见衡量指标是CPI（消费者物价指数），衡量商品和服务的物价走势。
经济学家用于形容和解释经济学的公式有一大堆--凯恩斯主义、货币主义、新凯恩斯主义等。但里面没有一个长期好用的。
形成原因：经济体当中流通的货币量超过了经济的体量（过多的货币追逐过少的商品）
各国央行的首要目标就是稳住物价。
对于经济体而言，我们通常追求的是更高的产值（GDP）
**通货膨胀其实是一种无时无刻不在进行的财富再分配**
![[Pasted image 20260101095940.png]]
非必要不花钱会陷入通缩。

恶行通胀会导致社会整个经济的金融系统、信贷系统基本上完全瘫痪、社会生产力骤减。
通缩，经济过冷给冻住了；通胀，经济过热开始自燃了。
通胀对股价和房价的影响说不准，因为干扰因素过多。
IMF报告指出不管是发达国家还是发展中国家，股价和通胀是负相关的。
	这其实是因为在通胀时期，不论是货币政策还是财政政策，政府和央行为了抑制通胀，大概率会采取紧缩的政策，而紧缩政策导致股价下跌。

通胀的三大诱因：
1. 需求拉动型通胀。
![[Pasted image 20260101101334.png]]
政府刺激经济就会从刺激总需求入手。比如搞基建、项目补贴、直接给钱。
总需求增长会导致物价上涨，但里面有个副作用 -- 物价上升。
经济增涨和通胀是一个绑定的套装。
当经济体中还蕴藏着非常巨大的潜力产能的时候，钱砸进去看到的是经济增涨，甚至会感觉不管多少钱进去看到的都是经济增涨而非物价上涨。
产能可以看：失业率。
	这也是高通胀前会伴随一个失业率很低的阶段。
	凯恩斯主义里面有个菲利普斯曲线 -- 通胀和失业率之间呈负相关。
社会上劳动力趋于饱和会导致涨价。
大量的量化宽松、长期的低利率这种手段，实际上钱还是只在金融体系中打转，有时会看不到实体经济的增涨，只能看到股市在哪里框框涨。

2. 成本推动
成本上涨，企业的利润率下降，逼不得已给产品涨价，而这个涨价就转嫁给了消费者。

供给推动的通货膨胀，不光通膨，经济也会受到打击。但卖原材料的公司除外。

3. 过量的货币供给
历史上几乎所有的恶行通胀，无一例外都是因为政府没有节制地印钱导致的。
政府印钱印的太猛了，通胀涨的太快，高到一定程度的时候，社会的财富分配就非常快了，大家会减少工作，导致产能下降，致使商品数量减少，价格就会上升。

通货膨胀有一个非常重要的性质 -- **预期的通货膨胀会导致通货膨胀**。
当预期通胀的时候，个体手中的钱变烫手，会自主增加消费或者超前消费，如果经济体中每个人都这么想的话，那么钱在每个人手中停留的时间就变短了 -- 即增加了货币的流通速度。
	当市场预期通胀的时候，货币的流通速度是增加的，即使是在货币总量不变的情况下，流通的货币量增多如此循环，哪怕银行没有印钱，但通货膨胀就会自主发生。
# 银行
长椅，意大利语叫Banco，后来演变为bank。
印钱的职能归于各国央行，银行的商业模式变得简单主要是三板块：
1. 拿钱，吸收存款
2. 用钱，放贷投资
3. 金融服务，受手续费
银行可以使用存贷利差来赚钱。评价银行的重要指标就是信贷差。
银行作用：通过资源调配，来释放整个社会当中的生产能力和消费能力。
钱通过自己的流动调用整个资源的流动，钱的流动看银行。
有个衡量国家债务的指标--**私人债务/GDP**

政府希望银行达到的状态--尽可能把钱贷给那些有能力偿还的人。
**货币乘数理论**：央行要求银行把一定存款的比例放到央行保管来保证自己具有足够的流动性。
银行是资源配置的中介，又能决定经济体中的货币量，可以说它是所有资源交通的枢纽。
国有四大行：
- 中国工商银行（ICBC）管商业
- 中国建设银行（CCB）管基建
- 中国银行（BDC）管外汇
- 中国农业银行（ABC）管农业
又陆续出现了股份制银行和城商行/农商行，刺激四大行活性。
后来加了：中国储蓄银行（PSBC）、交通银行（BOCOM），即六大行。
政策性也给剥离出来了，形成政策银行：
- 国家开发银行（CDB）
- 中国农业发展银行（ADBC）
- 中国进出口银行（CEXIM）
最开始四大行依然是四大天王。

专项贷款：央行想要扶持某个领域，就会支撑六大行多贷款给谁
专项再贷款：钱你可以找我要，但钱必须贷到这个领域中去。

但有个问题都贷给大企业了，小微企业利润少风险高不愿贷。
发展 **普惠金融** 利用互联网产业，首批试点了五家民营银行：微众、华瑞、民商、网商、金城。
需要打钱大规模的时候，找政策性银行、六大行；需要渗透的话，就搞互联网数字银行。

从普惠角度讲，大多数人的理财目标并不是冲击高收益，而主要是让财富保值，或在风险可控的情况下让财富增值。
现在是：以国有大型商业银行为核心，股份制、城商行和民营银行覆盖多元化的银行体系。
不同国家有自己的方法去监管银行从而调控经济:
- 美国是由松收紧以市场为导向
- 中国是由紧放开，政策主导去调控
# 国债危机
国家的收入（通常来自税收）通常高于开支，也就是持续的财政赤字。
多出来的钱来自于发行国债跟全社会借钱来补这部分资金缺口。
债务上限，国债数量不能超过这个是一个 **象征性** 的线。

亚当斯密：反对政府花钱，觉得市场竞争才是最高效的。
如果政府一直不介入市场，那么经济就每隔一段时间崩一次。
凯恩斯：市场也会失灵，政府不能完全不管，你得管（刺激它），尤其是在经济萎靡的时候（政府把钱借过来帮它花，以此来增加社会总需求）。
现代货币理论（MMT）：政府就该理直气壮地去借债，因为政府花的越多，非政府的市场就赚的越多。
	政府的信用本质就是钱，只要没有通货膨胀就应该使劲接花钱。

政府借国债时会有个度，但具备平常人不具备的能力--印钱。
- 央行才能印钱，政府就能借钱。
央行不能直接印钱给政府花，但它可以通过市场去买国债 -- **量化宽松**
- 内债：一个国家用本地发行的国债。缓冲器
- 外债：从海外借的，一般以美元计价的债称为外债。放大器

限制国债发行的因素：
1. 利率。可以通过政府和央行相互打配合绕过去。
利率是金融市场的核心，而国债又是利率的核心，因为它的价格决定了无风险利率。
	国债发行增多 -> 国债供给增加 -> 国债价格下降 -> 对应的无风险利率就会上升 -> 整个经济对应的利率都会跟踪上升
	这个效果和加息差不多，即抑制消费、抑制投资、抑制经济、抑制一切。
政府有一招可以对抗利率上升 -- **量化宽松**
2. 通货膨胀。
唯一的解决方法就是紧缩，通过抑制整体经济来给物价降温。

只要不碰到这两条红线，发多少债就是政府在增长和稳定之间的权衡取舍。
债务红线不是绝对的数字、也不是说它和GDP就是个绝对的比例，取决于这个国家的经济环境。
如果利率、通胀比较低，大家对政府很信任，即使你玩命地借债数字看着很吓人，但在经济上可能什么事情也没有。

国债印多了，通胀起来了，怎么办？
- 紧缩。借钱太多就少花点钱、少借点债
- 干脆违约或债务重组。
政府破产了，其实投资人也不能拿它怎么着。
现在政府违约最大的后果就是信用下降，这样你之后融资成本就会很高。
现在的经济体都是建立在信用之上的，越发达的经济体，就越依赖信用。
- 拖着。
要么借钱：借新债还旧债；要么干脆印钱花； 或同时。
这三种方式，只有拖着是具有扩张性的（短期内最不痛苦）。这类政策大概率最收到民众的欢迎。
# 避税
公司要交企业所得税，如果在一个国家经营比较好算，跨国的话就复杂很多。
- 一般针对跨国公司，看产品在当前国家产生了多少价值，这个价值增加的部分需要给这个国家交税
	通过区域征收的方式，跨国公司商品按其价值产生的分布，把钱交给了对应的国家。
实际灰色操纵很多。
- 界定商品在各个国家之间产生了多少价值，尤其是很多子公司之间来回交易
- 各个国家税收条款不一，还有各个国家所得税也不一。作为跨国公司肯定想的是把利润挪到税率比较低的国家，并且利用国家的规定把税避到最多
## 苹果怎么做的？
美国全球征税：但凡公司注册在美国，就是美国公司，不管你在哪个国家赚的钱，都要给美国交税。但有口子--只要你的钱不拿回到美国就不用交美国的税。
所以苹果在海外持续囤积了大量现金，海外部分也要避税：
1. 找到一个税率非常低并且各方面条件都很适宜的国家
2. 想方设法把尽量多的海外利润转移到这个国家
最终选了爱尔兰，为什么不选Tax Haven（避税天堂，如维京群岛、开曼群岛这些）？
	因为苹果要脸，你把收入放在黑盒子里，是要干什么见不得人的事，对品牌影响很大

苹果很大一部分投资都是像商标、专利这种无形资产上面投的，如果全部交税，不合理。
	所以就会让商标、专利所在国家海外公司（爱尔兰公司），那这公司向要交税国家收一笔钱 -- 对这些知识产权的使用费（Royalty Payment），比如刚好收到把税（利润）给抵了。
	这种无形资产，可以通过各个分公司之间，靠 Royalty Payment 收费来转移利润，即左手倒右手，那么只要不离谱你说多少是多少
在美国本土研发，为什么爱尔兰收苹果的税？
苹果整出来一套 **研发成本均摊计划**：就是爱尔兰公司付钱让美国公司研发，这样爱尔兰就可以向全世界征收我的知识产权费了。

可是爱尔兰交税虽然低（12.5），但也要交税？
- 因为但是爱尔兰税法有漏洞，它是根据公司是由谁管理和控制来征税的。
因此苹果只要让爱尔兰公司被另一个海外公司控制，那么你压根不在爱尔兰征税范围里，这样就巧妙地避掉了税。
	实际比上面（这行到这章开始）的复杂很多，需要这种手段层层嵌套。
	这种玩法，有个名字**Double Irish**（双层爱尔兰架构），还有一种**Double Irish with Dutch Sandwich**（双层爱尔兰夹荷兰三明治架构）
**大部分**（可以理解全部） 美国跨国公司都是这套操纵。

# 美联储
美联储, 全称叫做联邦储备系统(Federal Reserve System), 简称Fed
而Feds 指FBI的黑话, 即条子
美联储是由12个地区储备银行组成的系统, 每个储备银行都是由这个地区里面上千家成员银行控股.
涉及到关键的货币决策是在中央的一个集中的决策层 -- 联邦公开市场委员会(FOMC), 这里面的12个人成立了真正决策美国所有重要货币政策的组织.
12个人中
- 有7个叫执行委员包括了其中一个是美联储主席, 主席位置四年一届, 其它六个成员任期是14年; 这7个全部由总统任命, 参议院通过就可以直接上任
- 剩下的5个由地方主席轮值担任, 由于纽约联储太重要, 因此实际是4个位置由11个地区轮值担任
这12个人派系分为:
- 鸽派，放松、降息、刺激、多印点钱这种。
- 鹰派，锁紧。

印出来的钱相当于零息贷款。
两个最大目标：稳定的物价 和 最大化就业。但是这两个目标经常会冲突。
货币政策手段主要是控制利率（联邦基金利率）。
利率不行就走了量化宽松。
这个量化宽松导致了 -- 缩表恐慌事件（Taper Tantrum）。
各国央行都有这个问题 -- 可以决定因多少钱，花多少钱，但无法决定花在哪儿（股市还是实体经济）

金融本质是一个杠杆游戏，即风险和收益之间的权衡取舍。但是由于有了兜底的游戏机制，就导致了风险和收益其实不对等。
事前监管比事后救市更重要。美联储透明化很值得称赞。

# 避税天堂
避税和逃税不一样，避税是合法的，逃税是违法的。
所在地（A地） 和 赚钱（B地）都可以收它的钱。
收税根据两种原则收税：
- 属地原则：凡是该地方发生的收入，不管你是哪国人都要给地方交税。
- 属人原则：凡是你是我的居民产生的收入，不论你是在哪个国家赚的都要给国家交税。
几乎所有大部分国家是属地的，大国是属人的。
知识产权可以模糊掉**赚钱地（B地）**
避税天堂同时具备**低税率**和**私密性**。
利用BVI隐藏信息，可能是其不想对公众 或 国家的政府公开，并不代表这些活动是非法的。

# 化债

# 贸易逆差
贸易逆差，就是一个国家的总进口额 > 总出口额。
- 进口额太多，因为国外商品太便宜，吸引海外消费者去进口它们的商品
- 出口额太少，制造业竞争力不足，成本压不下来
什么导致贸易逆差？因为经济体的储蓄率不足导致的。
![[Pasted image 20260411074947.png]]
即，贸易差额 = 总储蓄 - 总投资
- 总储蓄，一年的收入减去消费
- 总投资，指那些真实带动生产力的投资
当没有贸易差额的时候，它的总储蓄就等于它的总投资。

为何储蓄率不足呢？两种问题解决（减小贸易逆差）：
1. 鼓励民众少消费、多存钱、多储蓄
2. 政府赤字太严重了，政府要少消费、多存钱、多储蓄
此外，汇率升高、进口增加、出口减少，就会导致贸易逆差；反之，则贸易顺差。
外汇还是一个非常灵敏的自动调节装置：
	国家贸易逆差的时候，不停的进口，需要不断地买它国货币A卖自己货币B，那么B就有贬值的压力，贬值就会刺激出口抑制进口，这样就能逐渐达到平衡态。
 
为什么会有持续的贸易逆差？
- 人为干预市场，扭曲这个调节机制（出现本币被高估导致贸易逆差）
- 外汇自动调控的不仅是这个国家的贸易平衡，而是整体对外的一个**资本流动** -- 不仅是卖商品、卖服务带来的资本流动，还有资本本身的流动。

# 期货
期货，全名 “期货合约“，指甲方和乙方约定在某个特定的事件点以约定的价格交易某个商品。
- 定量：到期时间、商品内容已经约定好。这个合约可以在市场上自由交易
- 甲方即多头，乙方即空头
预期未来要买，就做多；预期未来要卖，就做空。提前锁定价格来对冲风险。
合约的价格通常和现货非常接近，有波动值：如利率、贴现、风险溢价等等因素的影响。
期货，可以紧密追踪一个商品的价格，但又不需要真正交割这个商品

---
所有客观可以量化，即可以赌某个数的指标都可以进行期货交易。
只要有足够多的人愿意交易它，那么交易所就可以创造出来一个对应的期货合约。
**一切指标皆可期货**

---
期货合约有：
- 利率类期货
全球所有期货中，面值成交量最大的期货产品是 SOFR期货。
SOFR，银行间隔夜拆借利率的简称，它的期货就是 在到期日之前的一段时间每天利率的一个加权平均。
还有一类 -- 国债期货。
为什么利率类期货交易量这么大？ 
	所有的基金，所有的投资组合都有利率风险，无一例外

- 股票类期货
主要是 -- 股指期货，交易量比较大的，如追踪纳斯达克100指数、标普500指数、斯托克50指数、日经225指数、沪深300指数
股指期货，可以作为整个大盘的一个代表，最常见的用法是用来对冲掉整体市场的风险。
	带有增强、中性、对冲这种字眼的基金，大概率 -- 多运用做空股指期货来对冲

- 大宗商品
交易量较大的，比如原油、天然气、黄金、白银、铜、咖啡、大豆、小麦、糖、可可、棉花、螺纹钢、PVC等期货

- 其它
如，外汇期货市场。
VIX期货，即股票波动率的一个期货，它是追踪标普500这个指数隐含的一个波动率
更奇葩的：天气、碳排放权、葡萄酒期货等
