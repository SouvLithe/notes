## Basic element

### 环境
环境是保持 name 和 value 对应关系的记忆，环境（frame）知道name的含义。

绑定名字和值的方式： import语句，赋值语句，def语句。
环境分为：  全局框架  和  局部框架。
结束调用时，frame会自动回收，frame以栈的形式储存。

闭包： 指一个内部函数引用了外部函数的局部变量，当外部函数执行完毕后，内部函数和相关引用环境组合而成的实体，可用于数据隐藏和保持状态。
Ps： 内嵌函数常用

### 高阶函数
一种可以 接受函数作为参数 或 返回函数作为结果 或两者都有的函数。
例如：map，filter，fold（Python中没有fold）。
lambda函数：使用赋值语句将一个参数绑定到一个 name 上。是一个**匿名函数**。

#### Function Currying：
将多参数函数转换为一个单参数高阶函数的行为（可用多层嵌套函数实现），该函数返回一个接受其余参数的函数。
>柯里化是一种有副作用的函数：
>有副作用的函数的典型是修改全局变量（或依赖全局变量）
>很难放入多线程、多进程里面去.
>无副作用的函数特征：
>仅依赖输入参数产生输出，不改变外部状态。

==注意==：非纯函数无法在赋值语句中用作表达式（如print）

#### 函数抽象：
指给某个计算过程起个名字，然后在整个过程中都用这个名字来引用，而不用担心具体的实现细节。

好例子：
```
def delay(arg):
	print('delayed')
	def g():
		return arg
	return g  
#delay（delay）（）（6）（） 输出为===> delayed delayed 6   
```
主要是为了避免混淆闭包的概念，里面传了一个 函数delay 作为参数和一个参数 6 ，两个delayed都是由 print 打印的。

#### 装饰器：
python一个利用高阶函数的特性，并不是所有程序员都会高阶函数。
```
@trace1                       |  def triple(x):
def triple(x):                |      return 3*x
	return 3*x                |  trace1(triple)
```
左右两者等价

#### Recursion递归：
一个函数要么直接调用自身要么间接。一种分治的思想（数学归纳法）。
递归的组成：
>1. def语句的头部和其它函数一样。
>2. 递归函数通常以一个检查 ”基本情况“（解决问题的非常简单的版本） 的条件语句开始。
>3. 基本情况是在 没有递归调用情况进行 或 递归到底 的情况下进行

Mutual Recursion（相互递归）：指两个不同的函数相互调用。
Convert Recursion to Iteration：可以将递归转换成迭代的实现方式。（ **递归是迭代的一种情况** ）

==注意==：递归 = “信仰之跃”； 如果实现方法同样清晰选择最短的那个；
       在编译递归时，把基本情况放在最前面。
常见例题：计算分区--递归分解（给50块，用不多于20元方法找零，有多少种方式？）

### 抽象数据

抽象数据可以让我们将复合对象作为一个单元操作。

有利于维护抽象屏障。

>字典：可增删改，通过键查。
>元组：两个可加。

这三者都可做字典的键。
==注意==：如果不可变值包含可变值，则对象仍然可变。
身份运算符： is / is not 查的是物理地址。

OOP的函数式编程的思路：
>==约束器==：用于创建对象实例。通常是一个函数，接收一些参数并返回一个包含内部状态和方法的对象。
>==连接器==：连接器用于访问对象的内部状态。它们通常是对象内部定义的函数，用于获取或设置对象的状态。
>==详细过程==：当连接器被提供一个值时（被用户或 被链接到它的约束器），它会唤醒所有相关的约束（除了刚刚唤醒的 约束）来通知它们它得到了一个值。每个唤醒的约束之后会调查它的 连接器，来看看是否有足够的信息来为连接器求出一个值。如果可 以，盒子会设置这个连接器，连接器之后会唤醒所有相关的约束，以 此类推。

## 多态函数（Polymorphic Function）
指的是一个函数能够以不同的方式处理不同类型的对象，但调用方式保持一致。（几乎适用于所有数据类型的函数）
例子： repr和str 

### 多态的两种主要形式
1. **编译时多态（静态多态）**
    
    - **方法重载（Method Overloading）**：同一个类中定义了多个同名方法，但参数类型或数量不同。调用时，编译器根据参数类型和数量选择合适的方法。
        
    - **运算符重载（Operator Overloading）**：通过重载运算符，使其能够处理不同的数据类型。例如，`+`运算符可以用于整数相加、字符串拼接等。
        
2. **运行时多态（动态多态）**
    
    - **方法重写（Method Overriding）**：子类重写父类的方法，从而实现多态行为。调用时，运行时环境根据对象的实际类型选择合适的方法。
        
    - **鸭子类型（Duck Typing）**：只要对象有相应的方法或属性，就可以调用该方法或访问该属性，而不需要显式地声明类型。

### 表示（Representation）

## 测量效率（Measuring Efficiency）
增加代码效率的方法。
课外的：主要方法是两种  ---->  增长法  和  分治法  。

### 记忆化（Memorization）
思想：记住之前算过的结果，当再次使用它们时可以直接使用，不必重新计算。
限制：只能记忆纯函数，并期望它们的行为保持不变。
常用情况：在递归时比较常用。

### 乘方（Exponentiation）
基本思路是：将降低增长量级，从而加快效率。
数学领域。
**从低到高排列，这些函数增长量级的大小关系如下：**
$$

 O(1)<O(logn)<O(n)<O(nlogn)<O(n2)<O(n3)<O(2n)<O(n!)
$$

### Macros（宏）
**宏：可以操作代码的代码。**

| 特性         | Scheme 引用（quote）               | Scheme 准引用（quasiquote）                                    |
| ---------- | ------------------------------ | --------------------------------------------------------- |
| **语法符号**   | `'` 或 `(quote ...)`            | `` ` `` 或 `(quasiquote ...)`                              |
| **基本功能**   | 将其后的表达式直接作为数据返回，不进行求值          | 大部分与引用类似，但可以使用“未引用”（unquote）来在特定位置插入求值结果                  |
| **是否允许求值** | 不允许，整个表达式被当作数据处理               | 允许在特定位置（通过未引用）插入求值结果                                      |
| **未引用语法**  | 不支持                            | `,` 或 `(unquote ...)` 用于在准引用中插入求值结果                       |
| **应用场景**   | 适合直接生成数据结构（如列表、符号等）而不进行求值      | 适合在生成数据结构时需要部分求值的场景，例如构建代码片段或数据模板                         |
| **复杂性**    | 简单，易于理解和使用                     | 相对复杂，需要理解未引用的使用方法                                         |
| **示例**     | `'(+ 1 2)` 返回 `(+ 1 2)`，不会计算结果 | \`\` `(1 ,(+ 1 2) 3)` 返回 `(1 3 3)`，其中 `,(+ 1 2)` 被求值为 `3` |
| **嵌套使用**   | 不支持嵌套引用，引用内部的引用无特殊意义           | 支持嵌套准引用，可以通过嵌套的未引用实现复杂的求值逻辑                               |

>2. 运行时错误。 执行python解释器前检测到的错误，你会看到 Traceback（进行什么时候报错，哪一行报错）<--> 但不意味着依靠这一行修复问题。
>   报错是会跟着一个\<stdin\>,就是standard in
