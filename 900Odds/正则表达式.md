
## 元字符

| 元字符      | 说明                                      |
| -------- | --------------------------------------- |
| `.`      | 匹配任意单个字符（除换行符 `\n` 外）                   |
| `^`      | 匹配字符串的开头                                |
| `$`      | 匹配字符串的结尾                                |
| `*`      | 匹配前面的子表达式零次或多次                          |
| `+`      | 匹配前面的子表达式一次或多次                          |
| `?`      | 匹配前面的子表达式零次或一次                          |
| `{n}`    | 匹配前面的子表达式恰好 n 次                         |
| `{n,}`   | 匹配前面的子表达式至少 n 次                         |
| `{n,m}`  | 匹配前面的子表达式至少 n 次，但不超过 m 次                |
| \`       | 表示“或”的关系，匹配左右两边任意一个表达式                  |
| `()`     | 捕获分组，将括号内的表达式作为一个整体进行匹配，并且可以对捕获的内容进行引用  |
| `[]`     | 匹配括号内任意一个字符                             |
| `[a-z]`  | 匹配任意一个从 a 到 z 的小写字母                     |
| `[A-Z]`  | 匹配任意一个从 A 到 Z 的大写字母                     |
| `[0-9]`  | 匹配任意一个数字                                |
| `[^...]` | 匹配不在括号内的任意一个字符                          |
| `\`      | 转义字符，用于将元字符转义为普通字符，或者将普通字符转义为特殊字符       |
| `\d`     | 匹配任意一个数字，等价于 `[0-9]`                    |
| `\D`     | 匹配任意一个非数字字符，等价于 `[^0-9]`                |
| `\w`     | 匹配任意一个字母、数字或下划线，等价于 `[a-zA-Z0-9_]`      |
| `\W`     | 匹配任意一个非字母、数字或下划线的字符，等价于 `[^a-zA-Z0-9_]` |
| `\s`     | 匹配任意一个空白字符，包括空格、制表符、换行符等                |
| `\S`     | 匹配任意一个非空白字符                             |
| `\b`     | 匹配单词的边界                                 |
| `\B`     | 匹配非单词边界                                 |

## 选项
| 选项  | 说明                                                       |
| --- | -------------------------------------------------------- |
| `i` | 不区分大小写（Case-insensitive）                                 |
| `m` | 多行模式（Multiline），使 `^` 和 `$` 匹配每一行的开头和结尾，而不仅仅是整个字符串的开头和结尾 |
| `s` | 单行模式（Single-line），使 `.` 匹配包括换行符在内的任意字符                   |
| `g` | 全局匹配（Global），匹配字符串中的所有可能的子字符串，而不是只匹配第一个匹配项               |
| `u` | Unicode 模式，使正则表达式支持 Unicode 字符                           |
| `x` | 忽略模式中的空白字符和注释，使正则表达式更易读                                  |
