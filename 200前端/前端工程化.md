## YAPI
`YApi `是高效、易用、功能强大的` api `管理平台，旨在为开发、产品、测试人员提供更优雅的接口管理服务。

## 前端工程化
前端工程化：是指在企业级的前端项目开发中，把前端开发所需的工具、技术、流程、经验等进行规范化、标准化。
1. 模块化 JS、CSS
2. 组件化 UI结构、样式、行为
3. 规范化 目录结构、编码、接口
4. 自动化 构建、部署、测试
