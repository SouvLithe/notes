# 基础信息
完全信息博弈：在行动前，所有之前的行动都可被观察到。
非完全信息博弈：在行动之前参与者并不知道之前的行动。

严格优势策略：在对手任何选择下，收益都**严格优于**当前战略的一种战略
严格劣势策略：与优势相反
- **正和博弈**：参与各方的利益总和增加，实现共赢或整体进步（如贸易合作）。
- **负和博弈**：参与各方的利益总和减少，造成两败俱伤或整体损失（如两败俱伤的战争）。
- **零和博弈**：参与各方的利益总和不变，一方的收益必然来自另一方的损失（如赌博）。
先发优势：先看结局再看开局的思维方式。
有时候知道的信息越多对你越不利

猜疑链：人会在多次重复博弈过程中尝试修正自己的行为。
中间选民定理：模型总是有抽纰漏的，建立好模型看看有无纰漏，并添加约束条件。

# 原始博弈
纳什均衡：一个稳定的结果。是一种策略组合，其中**没有**参与者有动机**单面**改变自己的策略。
逆向归纳法：看最后一步，行动权在谁的手上。
![[Pasted image 20260317184735.png]]
- 可信度是关键：一个威胁或承诺的力量取决于兑现它的动机。
- 从未来推理：要找到现在的最佳路径，先确定终点的理性结果。
- 顺序即策略：行动的顺序和谁知道什么，可以完全改变结果。
- 承诺的力量：能够做出一个可信的先发行动，可以创造巨大优势。
临界点：博弈有两个稳定的均衡，两者间存在临界点，一旦超过就会达到另一个均衡。
人为地破坏一个均衡就会达到另一个均衡。
弱纳什均衡：没有促使人们变动地动机，亦没有促使人们不去变动的动机。


**帕累托最优（Pareto Optimality）**：指资源配置已达到“不可能再让任何一个人变得更好，同时又不让至少另一个人变得更差”的理想状态。
**帕累托改进（Pareto Improvement）**：指从一种状态向另一种状态转变的过程中，**至少让一个人变得更好，而没有让任何人变得更差**。

古诺模型：两家公司同时选择产量，每家公司必须预测对方的选择。
斯塔克尔贝里模型：一家领导者公司先行动，一家追随者公司观察并作出反应。
两阶段完全但不完美信息博弈：参与者了解规则和收益，但在各阶段内同时行动，不知晓对方当前的选择。（银行挤兑、贸易博弈）
	最终阶段的理性结果，称为第一阶段的已知事实

# 重复博弈：
- 如果阶段博弈G有唯一的纳什均衡，则对任意有限的T次博弈，重复博弈G（T）都有唯一的子博弈精炼解
有限博弈：已知终点，逆向归纳法使用，合作瓦解。
无限博弈：没有已知的终点，“未来的阴影”让合作成为可能。
	方法：确切写出这一次诱惑与下一次奖励之间的对比

合作的本质：
	在一个正在进行的关系中，对于将来奖励的承诺和未来惩罚的威胁，可能会为现在的好行为提供激励。

冷酷策略：以合作开始，只要对方合作，就继续合作。一旦对方背叛，就永远背叛。
	这个威胁却决于 **贴现因子** -- 一个介于0~1的数字，代表参与者对未来收益的重视程度，越高表示越重要。
	只要贴现因子大于等于 四分之一，那么长期合作的总收益就会超过短期背叛的总收益

# 动态博弈
动态博弈的中心问题：可信度。一个实际造不成威胁的威胁不是威胁。
扩展式表述：1. 参与者，2. 何时行动，3. 可选行动，4. 掌握的信息，5. 各行动组合的收益。

对于不确定的选择，可以使用**信息集**：一组决策节点的集合，  
1. 轮到同一个参与者行动。  
2. 该参与者不知道自己具体在哪一个节点
子博弈精炼
子博弈精炼纳什均衡（SPNE）：一个纳什均衡是子博弈精炼的，前提是参与者的战略在原博弈的每个子博弈中都构成纳什均衡。

# 当信息不对称
贝叶斯为分析不确定性下的战略行为提供了严谨的框架，当参与者拥有私人信息时尤为重要。
类型：参与者的私人信息，一个玩家的类型决定了其收益函数。玩家知道自己的类型（性格，长期 or 短期？），但不知道他人的。
推断：玩家对其它参与者类型的概率判断。
不完整信息下的解 -- 贝叶斯纳什均衡：
- 定义：没有参与者愿意改变自己的战略，即使这种改变只涉及一种类型下的一种行动
- 策略：一个完整的计划。它是一个函数，为玩家的每一种可能类型都指定一个相应的行动
所谓“**对手行为随机**”，其实只是对手因为不了解你的**私人信息**而产生的不确定性。
# 不可信的威胁
精炼贝叶斯均衡。
均衡的阶梯：每往上一级，我们的分析就越强，就能过滤掉更多不靠谱不合理的结果。
![[Pasted image 20260317195432.png]]
引入参与者的 “推断” -- 在信息集中，行动的参与者对博弈进行到该信息集哪个节点的概率分布。
精炼贝叶斯均衡的4个要求：
1. **信念明确**：参与者在任何决策点都必须对自身所处位置**持有明确的推断**（一个概率）。
2. **理性最优**：基于上述信念，参与者在后续的每一步行动中都必须**理性选择**最优策略。
3. **路径一致**：在均衡发展的路径上，参与者的推断必须严格遵循贝叶斯法则形成（符合逻辑、理性）。
4. **意外修正**：对于偏离均衡路径的意外情况，推断也应在尽可能的范围内依据贝叶斯法则进行修正。
这个理论最厉害的地方在于：**推断被提高到和战略同等重要的地位**

# 如何证明你的价值
信号博弈：行动比言语有用多了
- 定义：两个参与者之间的非完全信息动态博弈，发送者试图向接收者传达其隐藏的“类型”
凭什么你的这个信号别人就信？
- 关键在于它的成本：对于想假冒你的人来说，模仿你这个信号的代价必须高到让它们觉得不划算，甚至根本付不起
![[Pasted image 20260317200934.png]]
- 发送者：拥有私人信息（“类型”），选择发送信号以影响接收者的行动。
- 接收者：不知道发送者类型，观察信号并做出最佳决策。
**混同均衡：** 所有类型的发送者都发出相同的信号。接收者无法分辨发送者的真实类型，没有获得新信息。
**分离均衡：** 不同类型的发送者发出不同的信号。接收者因此可以完美推断出发送者的类型。信息被成功揭示。

贫困会使得处于议价的劣势，迫使一群人基于达成共识。
