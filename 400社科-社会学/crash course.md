# ch01-什么是社会学
社会学是研究社会与人类行为的科学。
社会是一群共享文化和领土的人。
社会学视角：
- 从特殊中看到一般
- 从熟悉中看到不寻常
一般模式，由大量特殊个体的选择所构成的模式。
每个个体构成了模式的一部分，通过观察个体的选择，社会学家可以发现整体模式中的元素。
**社会定位** 是根据种族、社会阶级、性别、性取向、宗教信仰等对你分别的方法。
- 社会地位会限制限制你的选择
- 社会地位也会影响你掌握和学习到的关于社会的一切
社会定位会促成特定社会群体的 **边缘化**
如果一个社会群体被边缘化，意味着群体的社会定位在权力中心以外。
边缘化带来了社会上 不同种类的 **权力** 和 **不平等**
# ch02-主要社会学范式
有关社会学本质的3个模型：和谐运行的机器、争夺利益的群体、一群相互交往的人
范式，基本上是你思考问题的模型，是一套概念和理论，形成你对特定主题的观点。

在社会学，关键是理论范式--社会学家对社会世界的根本假设，指导它们思考和研究。
原始事实，经验现实的简单描述而不会翻译成结论等着你。（如何回答？）
- 每种回答都需要你对社会世界做出一些假设
- 不同的回答会在不同的场景中发挥作用
所有的科学学科都对世界做出假设，并且所有科学学科都根据它们提出的问题使用不同的视角
社会学观察社会的所有层面，从宏大到微观在各种各样的规模上
需要研究社会的不同平面，可以从主要理论范式开始（一共3种）：
1. 结构功能主义：社会被看作是一个复杂的体系，各部分协同合作以促进社会稳定、维护社会秩序
社会的不同部分，是社会结构相对稳定的社会行为模式，执行不同的社会功能。
社会功能分为：显性和隐性。
社会功能失调，指扰乱社会顺利运作的社会模式。
这种方式缺点：无法解释变革如何发生的。
2. 冲突理论：社会由许多不同群体竞争稀缺资源构成
阶级冲突理论，社会由不同阶级构成，阶级取决于人与生产资料的关系。
种族冲突理论：社会不平等是不同种族人群冲突的结果。
性别冲突理论：聚焦于男女之间的社会不平等。
3. 符号互动主义：社会学需要研究个体的社会情景，以及他们对情景赋予的意义
只有这个理论在研究微观。
对于该范式，不存在板上钉钉的事实，相对地它关注群体为互动和事物赋予意义所创造地世界。
# ch03-社会学与科学方法
科学方法：一般，你提出一些关于世界的问题，然后形成可检验的理论，解释你如何能回答这个问题。
科学方法扎根于哲学叫实证主义。
3种社会学研究：
1. 实证社会学，基于对社会行为系统观测的社会研究。
定量研究：通过使用数学或者统计学方法研究世界中可观测的关系。
定性数据：不是以数字形式表达的信息，而是尝试努力说明或者描绘有时不能在电子表格中提炼为数字的所需信息。
社会学作为实证科学存在限制：并非你想了解的有关社会的一切都符合可预测、可测量的范畴。
如果你想知道人们在真实世界中的表现，你将不希望你的研究方法会改变人们本来的行为。
	观察者对于参与者行为的影响，被称为 Hawthorne效应

2. 解释社会学，聚焦于人们赋予社会世界意义的社会研究
主观：被看作是人们对亲身经历赋予的意义。
接近研究对象，带着从研究对象的角度去看世界，而非通过定量数据看世界。
常用方法：访谈。

3. 批判社会学，聚焦于对社会变革的需要的社会研究
价值观：是人们对于什么是“好”的看法以及它们对于世界如何运作的态度。
对价值观的研究进行辩论，而非价值无关的研究是批判社会学的起源之一。
# ch04-社会学研究方法
1. 研究起源于一个问题，确立问题的关键在于 -- 定义研究的概念并确保大众同意这些概念的含义。

2. 陈述假设，对2个变量之间可能的关系进行陈述。
再给变量赋值之前，你必须把变量 **操作化** -- 必须定义你即将测量的变量以及你将如何测量它。
变量所得到的值，叫做变量的 **测量值**。
为了使你的测量值是 可靠的，必须以一致的方法测量变量。
为了使你的测量值是 有效的，变量必须真实测量能直接反映研究的概念。
**自变量**，影响人们如何描述自己的变量；还有受自变量影响的**因变量**。
相关关系（两个变量一同变化） 并不总等于 因果关系（一个导致一个变化）。

3. 收集数据
四种方式：
- 实验：设置对照试验
- 调查：通过普查抽样等，针对关注特定人群（目标人群）的回答
- 观察：研究者观察特定人群，通过加入它们的日常生活
- 现存资料研究：常见来源是政府机构。（重点在于，这类数据覆盖更广时间跨度更大与研究者自己的实验数据而言）

4. 把数据转化为能帮助你回答感兴趣问题的信息
两种方式：
- 归纳逻辑思维：采用你的观察结果，用它们构建理论
- 演绎逻辑思维：使用现存理论形成你要检验的假设
两者不是互斥的，研究者可以两个都用。
# ch05-自杀与社会
社会学研究 社会事实 -- 包含行为、思考、感受的规范和外在个体蕴含的强制力，这个强制力会对个体施加控制。
社会事实及其强制力，代表了一种 社会凝聚力。
共同意识/集体意识，指特定社会中属于社会事实的所有信念、道德和观点的集合。
犯罪，作为一种公共是非教育，有助于强化集体意识。
当有人被审判/惩罚，将会给公众展示社会的道德观，以及道德观的强制力。
社会功能失调，一种危害社会正常功能的东西。
社会由 社会事实 组成，通过 集体意识 凝聚在一起，这才是社会功能正常的运作方式。但社会同样可以被急剧的变化所破坏。
# ch06-卡尔·马克思与冲突理论
马克思认为：与其他动物相比较，人类对自然世界不可思议地不适应，
而在自然界唯一地生存方式就是改造自然 -- 一起重塑自然以适应人们地需求，即劳动。
自由问题地核心是劳动问题：劳动如何组织？谁从中获益？以及这种组织如何随时间变化？
- 经济，也就是社会中劳动和资源的组织是基础；
- 上层建筑，政治、文化、宗教甚至家庭建立在物质基础上的；

马克思以**生产方式**和**经济阶级**的角度看待历史发展。
马克思将生产方式理解为历史阶段 -- 原始共产主义、封建主义、资本主义都是生产方式。
生产方式，由生产力和生产关系的组合决定。
- 生产力，指经济中的基数、科学、物质的部分，也包括文化和社会技术
- 生产关系，定义人们如何以劳动组织
阶级并非真的由法律定义，而是由人在生产关系中的位置所定义。
- 无产阶级，指不占有或控制生产资料
- 资本家，占有工厂及其制造出来的产品，它们控制生产资料
生产资料，指你进行劳动和生产所需要使用的物质。
正是这种对生产资料的控制的差异，导致了资本主义以 雇佣劳动为形式进行剥削。
如果无产阶级不占有生产资料，那么他们就只有一样东西可以卖 -- 他们的劳动。
剩余价值就是利润。
生产过剩的危机 -- 生产力如此发达以至于生产出远超自身所需的商品，但大多数人根本买不起这样的商品。
生产力会受到生产关系的限制。
历史是阶级斗争的过程，每个阶级代表着生产力或生产关系。
阶级斗争，革命是打破 生产过剩 僵局的关键。
# ch07-杜波依斯与种族冲突
种族，社会建构的一类人群，它们拥有社会认为重要的生物学特质。
无处不在的种族新年和种族主义最终会自我强化，这就是 **种族形成理论**。
种族形成，指通过社会的、政治的、经济的力量影响社会如何定义种族类别，以及这些 种族类别 如何反过来最终形成这些力量的过程。（认为犯罪 -> 没钱没教育 -> 犯罪）
如今的种族政治在研究：
- 种族如何与政治权力和社会体制结构纠缠在一起？
如今的种族反抗在研究：
- 不同种族群体如何挑战和改变权力结构？
**种族冲突理论**的现代研究领域：**种族身份、种族形成、种族政治、种族反抗**。

# ch09-韦伯与现代
马克思韦伯关注理性化、官僚体制和社会分层这样的概念。
最能把现代世界和传统世界区分开的变化是 -- 我们的思考方式。
- 传统认为世界存在基本的秩序，而这个秩序就是一切事物应有的样子
- 现代一切都是可争取的，社会与人都在变得更加理性或经历理性化过程
理性包括3中具体的事情：**量化、条例明确的行为、反思**。
- 量化：如果知道输入，就能知道输出
- 条例明确的行为：一个可遵循的系统，量化得以产生是因为这条涉及其中
- 反思：思考你正在做什么，反思性地思考
韦伯认为理性的推进器是：宗教。
《新教伦理与资本主义精神》：传统向现代地转变，开始于新教改革。
判断宿命论的天选：你得到救赎的证据，在于你的生活过的怎么样。
这种公共的传统社会，转型为个人主义的、资本主义的关注经济成功的社会。

官僚体制是现代化转型的关键之一。
国家运行的方式改变：
- 由命令链极度明确的职位等级制度构成
- 官僚体制中的人使用技术能力 非人性化地 完成自身工作
国家服从的方式改变：
- 传统是通过 传统的正当性支配的
- 现代国家统治结合 合理合法的正当性（运用规则） 和 魅力感召的正当性（指定规则）
政党是社会分层的重要例证
社会分层 -- 指社会中的人如何根据所持权力被划分。
韦伯不认为卡尔的划分方式，认为有3种要素：
- 阶级，和卡尔一样，但是他不认为阶级存在共同利益
- 政党，被宽泛定义为寻求社会权力的群体
- 地位群体，由社会荣誉（包括尊敬和威望）所定义
这3种要素影响一个人在社会中的位置，更重要的是这些社会分层要素可以相互独立。
担心会不会锁死在官僚资本主义的 **铁幕** 中，即生活只剩下一系列基于理性化规则的交互，而缺乏规则背后的意义。
# ch10-符号、价值观与规范
文化，是非物质的对象，比如思想、行为、语言和价值 -- 与物质对象结合在一起，所形成的生活方式。
文化可分解为两要素：物体（物质文化） 和 思想（非物质文化）。
社会学家主要关注非物质文化有3种要素： 符号、价值观与信念、规范。
- 符号系统，指包括一切同文化的人所认定的携带特定意义的东西
- 价值观，人们判断好坏、对错的一种文化标志；信念，指人们认为在世界种真理是什么的具体看法。
- 规范，指导社会行为的规则和期望的准则。
人们的思维和行动受到它们所使用的语言创造的文化透镜的影响。
三种类型规范：
- 民俗，不言而喻的非正式小规则
- 民德，更官方的民俗，往往会书面立法成为社会的规则和法律（民德不是普世的）
- 禁忌，是社会道德中心非常关键的规范
# ch11-文化、亚文化与反主流文化
本章着重如何区分文化？文化的规则是什么？
永远不存在文化数量上的一致共识。
以社会阶级划分文化模式，文化影响阶级、阶级也影响文化。
- 低文化，即 **大众文化/流行文化**，包括在社会大多数人种流行的文化行为和思想。
- 高文化，指区分社会精英的文化模式
主流文化，包含与社会文化理想和价值观大体一致的文化模式。
亚文化，将社会人口划分成不同部分的文化模式。
拥有最多权力和社会影响力的文化群体决定 **规范** 是什么；没什么权力的人则退居 **亚群体**
单一文化支配其它的文化，并不是真正的融合。
民族中心主义，用其它文化的标准评判某一特定文化的行为。
多元文化主义，不把社会看作是一个同质化的文化、而是认可文化多样性，同时号召所有文化传统的平等立场。

- 有时亚文化可能主动地反对主流文化，这被称为反主流文化
- 发明创造不一定要是物质，思想也可以创造和改变文化
文化滞后，有些文化元素比其它元素变化地更慢。
- 文化传播，指文化特质从一个文化向其它文化扩散
符号互动主义所见，社会地一切都在我们所创造地共同现实和共同文化。
# ch12-社会与社会变化
社会就是一群共享文化和领土的人。
Lenski根据人类使用的技术和在技术帮助下产生和维系的社会组织，把人类历史分为5种不同类型的社会：
- 狩猎与采集社会
食物是这种社会最关注的事情。这种社会无法有效支持超过25~40人的群体。
- 种植与畜牧社会
首次发生历史上第一次物质积累过剩的问题 -- 群体持有的资源超出人口生存所需。
过剩促使社会发展，从而导致历史上第一次出现**社会专业化分工**。
- 农业社会
到达这种社会的时候，家庭开始变得不那么重要了。
家庭承担的部分功能（比如教育）开始由更大的社会机构代替（比如学校）。
- 工业社会
家庭的作用开始持续下跌，更多的社会机构开始取代传统家庭功能。
- 后工业社会
由计算机的发展所带来。
关键变化是，从基于原材料和制造业的经济，转移到基于信息、服务和技术的经济。

不同的社会并不是相互隔绝的。
社会变化由技术变革驱动，并非所有的变革都是有益的（战争、污染、全球变暖）。
技术并不解决根本的社会问题，技术有潜力重组社会。
随着科技的进步，同样也促进了社会不平等。
冲突和不平等，是由缺乏过剩和分享资源的需要来制衡的，这不适用于后现代社会。

社会历史是 团结 的长期变化--一个什么把社会凝聚在一起的变化。
- 相似性（机械团结），这个群体拥有相同的技能，以相同的基本方式生活
- 配合性（有机团结），一个小群体依赖另一个小群体的技能与产物
# ch13-人的社会发展
先天行为，指人类行为中生物决定的本能的行为。
后天行为，指基于成长中的人和环境所形成的人类行为。
这章主要讲这个后天行为，社会学家可以基于此提出很多不同的理论。

---
很大程度上，人们发展自身人格通过学习我们的社会和文化，是通过一个社会过程，叫**社会化**。
社会隔离会极大地影响我们地情绪和认知发展。
缺乏社会化，会影响儿童地语言能力、社会能力和情绪稳定。
人格如何发展：
- 本我，无意识的驱动力。对食物、舒适和关注的需要。
- 自我，是理性的声音，有意识地努力控制需求快乐的本我。
- 超我，是个体内化并用来指导自己选择的文化价值观和规范的构成。
认知发展的四个阶段：
- 感知运动阶段，所有的知识建立于你用五感能感知到的事物
- 前运算阶段，学习语言并通过提问题来学习世界，自我为中心
- 具体运算阶段，发展出能够采纳其他人观点的能力，开始对周遭事件建立因果关系（开始以抽象的方式思考，利用逻辑和批判思维）
- 习俗阶段（前中后三阶段），开始考虑更抽象的伦理概念，不仅是对和错
性别不同，会影响它们这四个阶段的发展。
- 男，重视正式规则来定义对和错，正义视角
- 女，重视道德选择中人际关系推理的作用，关怀与责任视角
社会发展理论：一切社会活动都要求你通过你之外的人去认清你自己，“扮演他人角色”
- 模仿学习
- 游戏学习
- 博弈学习
- 不同情况下扮演不同角色
最后一个阶段，不是通过具体的某个角色，而是通过概化的他人 -- 指所有我们文化规范和期望的表现。
在18岁后，人格依然会发展。
# ch14-社会化
我们都被人们所包围，这些人成为了我们行为和价值观的一部分。
社会化，通过学习社会和文化的社会过程人们发展人格和人类潜能。
家庭是你初始社会化的来源 -- 首次体验到语言、价值观、信念、行为和你所属社会的规则。
文化资本，帮助人们在这个世界取得成功的非金钱资产。
性别社会化、种族社会化、阶级社会化这些都是**预期社会化**的例子。

# ch15-社会互动与表演
社会活动，即人们根据他人做出行为和反应的过程。
社会结构，由人和群体的关系构成。这个结构指导并限制我们的行为。
人们之间的关系会根据社会环境对每个人建立特定的期待。
社会地位，人处在社会或社会群体中的位置。
- 先赋地位，人们无法选择的，一出生就有的
- 自致地位，赢得的、争取的，至少是通过一定个人努力获得的
首要地位，其他人最有可能用来识别你的地位。
如果社会是社会位置，那么角色就是与地位相配套的一组行为、义务和特权。
	角色是指南，是我们对于自己和别人对我们的期待。
不同的 角色丛，有时会要求同一个人表现出矛盾的行为。
角色冲突，当不同地位的配套角色制造出了矛盾的要求。
即使是一个地位中的角色也可以制造冲突，我们称之为角色紧张。
如果人们把情景定义为真实的，那么情景的后果就是真实的。
	使用假设和经验来定义什么是真实的。

人们名副其实地为彼此表演角色，社会互动的目的是维持符合预期的成功的互动。
为了做到这个人们需要仔细控制他人可以接收到的与自己有关的信息 -- 印象管理。
道具 和 非语言沟通 -- 符号载体，我们用来与互动的人传达印象的东西。
表演最根本的地方在于：观众看得到的和看不到的，前台和后台。
**每个人都在不断地表演**
# ch16-社会群体
社会群体就是一群人地集合，这群人有着共同点，并且相信它们的共同点是重要的。
即，群体一部分是由成员 **感觉** 自己属于的群体所定义的。
集群是一群个体恰好在同一时间出现在同一地点。
类群，指包括跨时间地点的特定种类的人，他们都有一些相同特征。
- 初级群体，小而紧密的绳结，由非常强的归属感捆绑在一起。
- 次级群体，大而非人化的群体，由共同目标或者活动联系在一起。
这些群体有一个共性 -- 都是 **自愿** 的，如果你属于一个群体那是因为你选择加入它。
也有非自愿群体，成员是指派的（比如监狱和军队）

群体动力学，即个体影响群体和群体影响个体的方式。
一个最好的切入点是 领导 -- 影响群体中其他人的人。
有两类领导：
- 工具型，专注于群体目标、发号施令、制定计划以及达成这些目标
- 表达型，追求群体和谐，化解群体内冲突
领导风格有三种：
- 权威型，通过发号施令，指定希望成员遵守的规则实现领导
- 民主型，通过与成员达成共识实现领导
- 放任型，极度随意，基本上对成员放任自流
群体从众，群体成员致力于遵守群体规范和标准。
群体思维，是群体内窄化的思想，成员相信正确的答案只有一个。
参照群体，用以作为标准去评判自己和他人。
群体规模，越大的群体越稳定，如果成员之间有分歧其它成员可以介入并协调。

看待社会的视角：
- 社会边界，把社会划分成有边界的组合，分为内边界和外边界
- 社交网络，这个视角把人看作全部都在社会性上相互连接的结点。
# ch17-正式组织
正式组织，高效实现目标的有组织的群体。
正式组织的三种组织类型：
- 功利性组织，为成员实现特定的功能
- 规范性组织，有时也叫支援团体，人们作为志愿者而加入的组织
- 强制性组织，是自己无权决定是否加入的组织

官僚体制，一种由理性构建以高效做事的组织。
有6个特点：
1. 专业化分工
2. 等级制度
3. 明确的命令链、通过正式文件联系
4. 以技术能力胜任工作
5. 每个人被非人化对待
6. 这些功能按照详细的规章制度进行
问题：繁文缛节、盲从法律规则，
官僚惯性 -- 指组织最终的目标变成只是为了延续自己继续存在，
寡头政治 -- 少数人支配多数人，
官僚异化 -- 官僚体制对体制内人员和要服务的对象可能是无人性的

寡头政治铁律，不管理论上官僚体制有多民主，实践上往往会成为纯粹的寡头政治
科学管理法：
- 他提出一套程序，管理者可以密切观测和系统量化工人如何完成工作，这样工作就能不断迭代优化、从而更加高效。

组织环境，组织存在和运行的环境，包括技术、政治、经济动向和人口结构。
快餐式社会，
快餐，你能快速符合期待地得到你的食物，这是事物的制作过程受到精确的控制
理性的非理性，理性的体系通常是不理性、非人性化的。
# ch18-越轨
越轨，指任何违反人们一般认为是正常地事情。
陌生人异样地阳光是一种社会控制 -- 社会约束人们地思想和行动的手段，通过限制或惩罚的越轨行为。
认可的反应，通常是针对从众行动。

为什么会出现越轨？
- 生物本质主义，人本质的生物缺陷造就了人的越轨
体型和犯罪行为之间的简单相关，不能作为因果证据，相反这可能是自我实现的预期。
- 心理学环境主义，尽管性格的有些特质可能是先天的，心理学家把人格看作是社会化的结果
好孩子：有更强的良知、擅长应对挫折、认同传统的文化规范；坏孩子相反。
好孩子更少和警察叔叔打交道，归结于这些孩子控制越轨冲动的能力。
这种认为越轨的本质在于冲动控制的思想，叫 **遏制理论**。
生物学和心理学解释只将越轨理解为 **异常**，两种方法都起始于寻找生理/心理的不同寻常。

社会学把越轨和犯罪看作是社会结构的结果，
基于3大思想：
- 越轨行为根据文化规范有所不同
- 人之所以越轨，是因为它们被贴上了越轨的标签
- 定义社会规范涉及到社会权力
# ch19-越轨与理论
越轨有四种功能：
- 越轨有助于界定文化价值观和规范
- 社会对越轨行为的反应澄清了道德界限
- 这些反应通过类似的方式使社会团结在一起
- 越轨能促进实际的社会改变
应变理论：一个社会的越轨数量取决于社会是否已经提供了足够的手段来实现文化定义的目标。
通过传统认可的手段实现文化上设定的目标。
对可接受的手段的一种反应是使用不可接受的手段。
仪式：对规则的深深热爱仅因为它们是规则。
撤退：一个人基本上退出社会，拒绝传统的手段和目标。
反叛，对目标和手段的拒绝，但在反文化背景下，支持以新手段追求新目标的人。
耻辱，一种强烈的消极的主宰地位，影响着一个人的自我、概念、社会认同以及与他人的互动。
污名化最大的影响是它将带来更多的标签，尤其是一个人已经做了或可能还在做的事情。
微分关联，你和谁交往或多或少地导致抑制越轨。
冲突理论认为规范和法律反映了强权的利益，因此有权势的人可以通过贴上越轨的标签来捍卫他们的权力。
