# 前言
核心观点：民族不是自古以来就存在的、基于血缘或共同起源的自然实体，而是一种在特定历史条件下被“想象”出来的、现代的政治共同体。
最著名的观点是：民族是一个想象出来的政治意义上的共同体，即它不是许多客观社会现实的集合，而是一种被想象的创造物。
指出这种想象的、创造性的方面并不等同于说民族主义是一种虚假的、人为的产物，而是一种新的、被创造的社会事实。
主义的结合促就了政治共同体。

民族主义现象进行重新叙述，有关民族主义的三重分类：
- 远程民族主义。这一民族主义综合了殖民地各阶层的诉求，反抗宗主国的压迫和不平等对待。**目的是建立属于自己的独立主权国家**
- 民族主义模式。通过这种语言民族主义的创造，一种取代帝国的、奴隶制和封建等级制的，即**主权的政治共同体**诞生了。**自上而下的、“横向”的、人人平等的“主权政治共同体”**
- 官方民族主义。即由国家由上至下推进的文化统一与政治统一的进程，通过在交流工具（印刷术）、普及教育和内政构造等各方面的强制推行，上层统治最终促使包含多样性的和 地方性的文化趋于同质化。**将民众的忠诚从地方领主转移到中央皇室**

不是民族产生了民族主义，而是民族主义创造了民族。

宗教、宗教共同体是思考政治、政治共同体的基本参照。
羞耻感是一种现世的共同体关系（民族的、家族的、 家庭的等）的普遍的情感特征
正是意识形态促成相同族群、语言和文化的社会走向分离主义，也正是意识形态 危机成为新型民族主义的动力及契机。
# 导读
通过三类制度为后殖民时期的民族国家预先设定了想象的“基本语法”：
- **人口调查**：将复杂的人口简化为种族、语言等清晰的量化范畴。
- **地图**：用几何学的、有边界的地图取代了模糊的、中心化的领土观念。
- **博物馆**：通过考古、重建和展示古代遗迹，为殖民地构建一个看似古老的、世俗的系谱。
“民族”这个“想象的共同体”最初而且最主要是通过文字（阅读）来想象的。但与过去在认识论上的决裂本身 不足以说明在诸多可能类型的“水平—世俗”共同体中，为何“民族”会 脱颖而出。要“想象民族”，还需要另一个社会结构上的先决条件，也就是“**资本主义、印刷科技与人类语言宿命**的多样性这三者的重合”。
“盗版”（`piration`）——自觉的模仿——的概念来衔接先后出现的民族主义

本书侧重两个问题：
- 第一，作为政 治共同体的民族与其他共同体（宗教共同体、族群共同体、家庭等等）相比，究竟有哪些不同的特征？如何辨识民族主义的情感方式与 其他情感方式的联系与区别？
 - 第二，《想象的共同体》所涉及的远程 民族主义主要产生于西半球（海地、北美等），那么，在东半球的东 南亚和中国，移民群体与民族认同的关系如何？
安德森极力区分爱国主义与种族主义——对他而言，种族主义的根源不是“民族”的理念，而是“阶 级”的意识形态。
