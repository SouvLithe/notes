# 音阶与记谱
音符，对应着一个固定频率的震动。
![[Pasted image 20260308204847.png]]
任意两个音之间的距离，叫做音程。
频率相差两倍的音程相当重要，被称为 八度音程。

音乐家在八度音程之间选择了几个结合起来不错的音符，用字母A~G命名
![[Pasted image 20260308205513.png]]
这几个音符的音程或者说频率的比值并不是相同的，而是分为两种 全音级 和 半音级。（二者恰好相差两倍）

十二平均律：把上面按照12分之1补全得到
![[Pasted image 20260308205536.png]]
除此之外还有十九平均律、纯律等不同律制。

仔细观察钢琴按键
![[Pasted image 20260308210141.png]]
发现其由几个重复的部分组成，每个部分（红框）又有12个键 -- 7个白键 和 5个黑键。
这就对应着八度音阶的音符。

为了将音乐记录下来，使用 **五线谱（staff）** 来记录音符。
![[Pasted image 20260308210532.png]]
五线谱分为5条线和4个间，音符的位置就在这些线或间上。
越往上音符音高越高，反之越低。

谱线可以提供音符之间的相对音程关系，无法确定绝对位置关系。
这时候，就需要 **谱号（Clef）** 发挥作用了
![[Pasted image 20260308210757.png]]
上面的是高音谱号（Treble），定下了音符G4的位置；下面的是低音谱号（Bass），定下了音符F3的位置。
在高音和低音谱号下，C4的位置刚好是对称的。

常见的钢琴谱上，高低音谱号共同使用，形成大普表。
![[Pasted image 20260308211308.png]]
音符的位置在5线之间写不下的时候，可以采取加线的方式进行拓展。
过高或过低的音可以采用**八度记号**，表示在一个范围内上移或者下移一个八度。
![[Pasted image 20260308211457.png]]

要表示`#C`,需要在音符前加一个#号（蓝），这个升号在无限谱的作用范围是一个小节，小节内的音符同样会被升高。
如果需要回到原来的音符，需要加上一个还原符号（红），把它变回原先的音高。
![[Pasted image 20260308212042.png]]
此外还有：
![[Pasted image 20260308211712.png]]

音符的个数是无限的，但在一个八度内可以选取几个特定的音程关系组成**音节**。
![[Pasted image 20260308212305.png]]

在某个音节中，充当着回归终止的角色，被称为**主音**。
音符的作用却决于它所在的音乐场景，效果是由这个音阶的特殊的音程排列关系导致。
很多时候，音乐的听感不是由音符的绝对频率决定的，而是由音符间的相对关系决定的。
根据主音，将音阶称为  `#大调音阶`.（`# 表示主音`）

在一个大调的音阶中，有两种方式给音阶的音符命名。
1. 采取数字记法
![[Pasted image 20260308213242.png]]
2. 音符的功能名
![[Pasted image 20260308213332.png]]
真正明确提示功能的，只有**导音**  --  拥有很强的引导旋律回归到主音的功能。
